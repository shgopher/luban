# 技术架构 · 完整知识目录

> **唯一一把尺子** (每章都能回答 “属于哪一层、哪一维”)：
>
> **内功 → 需求 → 技术 → 组织 → 附录**
> - **内功** = 前置能力 (算得动吗、代码组织得住吗)，**不属于 L0–L5 任何一层**，单列第零篇
> - **需求** = 架构的输入 (要什么、有什么约束)
> - **技术** = 严格六层 L0–L5 (底座)+ 应用层 (领域应用)
> - **组织** = 架构与人的关系
> - **附录** = 方法、案例、参考 (**不是知识域**，是练习与查证材料)
>
> **内功篇的取舍**：只写 “架构决策用得上的算法与模式”，不刷题、不复刻 23 种模式；代码全部用 Go。
>
> 全书 **12 篇 · 84 章 · 573 节**。
