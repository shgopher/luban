## 5 分钟入门：先记住这 9 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **大 O** | 只说 n 翻倍、工作量翻几倍 | 只说货多重 |
| **均摊** | 偶尔一次贵，摊到每次就便宜 | 年终奖一次补 |
| **哈希表** | 一步跳到位，但不保序 | 按货号直奔货架 |
| **堆** | 只保证最急的在最上面 | 急诊只认危重 |
| **布隆过滤器** | 说「不在」准，说「在」会错 | 门卫咬定「不是本楼的」 |
| **设计模式** | 变化点挪到稳定接口后 | 可换插头的插座 |
| **函数值** | 存个函数就换行为 | 遥控器改一个键 |
| **Control** | 怎么做（遍历/并发/重试），与业务无关 | 流水线：换产品不用改传送带 |
| **文法** | 把格式写成规则，动作写成回调 | 菜谱：换菜只换菜谱，不换厨房 |

> 记住：**复杂度管该不该担心，模式管该不该加层，范式管「业务和控制有没有分开」——算的是同一种账。**

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| 「复杂度低就一定快」 | 大 O 只比增长阶，常数与分配定胜负 |
| 「用了模式就是好设计」 | 没有第二个实现就只多一层跳转 |
| 「概率结构是拿准确率换内存」 | 三个参数：误差方向、上界、内存 |

## 读完自检（入门级 3 题）

**Q1** 同事说「这个函数是 O(n)，所以没问题」。你要补哪两个数？

▸ 答案：**这个 n 下的绝对耗时**和**均摊还是最坏**（最好给 P99）。O(n) 只说 n 翻倍工作量翻倍，常数与分配能拖慢量级。

**Q2** 1e6 条取 Top-100，堆快 142 倍。堆「没做」什么？

▸ 答案：**没建立 100 万条的全序**。堆只守 100 个候选，来一条比一次就丢；全排序要排完才能取。

**Q3** 接口只有一个实现、半年没改，是好抽象还是过度设计？

▸ 答案：偏向**过度设计**。两个数：实现数 = 1、近 6 个月变更 0 次；两版都 +7 行，它只是一次间接。
