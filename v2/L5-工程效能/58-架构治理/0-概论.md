## 5 分钟入门：先记住这 8 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **ADR** | 一条决策一张纸：写清背景、选择与代价 | 病历页：为什么开这个药 |
| **技术债** | 用未来利息换现在速度的一笔显式交易 | 刷信用卡买设备，月月还息 |
| **利息** | 欠债后每次改动都要多付的时间 | 分期手续费，越拖越贵 |
| **架构评审** | 不可逆之前，借一群人的经验换一次纠错 | 砸墙前先看水电图 |
| **演进路线图** | 从现状到目标分波迁移，每波有退出标准 | 搬家分三趟，每趟带清单 |
| **退出标准** | 什么条件算这波干完，可以进下一波 | 疗程结束看化验单 |
| **技术选型** | 预算与合规内用证据降不确定性，留退路 | 买车先试驾、先谈退订 |
| **重构三式** | 筛问题、争人和时间、分段落地 | 边开车边换轮胎 |

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| "ADR 就是设计文档，事后补一份也算" | ADR 记的是为什么这么选、放弃了什么、代价多大；补写要标明追溯记录 |
| "技术债要清零才算健康" | 债是显式交易，清零既不现实也不必要；看欠什么、利息多少、何时还 |
| "重构就是重写一遍" | 重构是飞行中换引擎：先筛问题、再争取人、最后分段落地；三式缺一就是无尽加班 |

## 读完自检（入门级 3 题）

**Q1** 为什么 ADR 的内容不改，只让状态变化？

▸ 答案：它记的是**当时的信息与权衡**，改内容等于篡改历史；要推翻就写新 ADR，把旧的标成「已替代」。

**Q2** 技术债的"利息"指什么？

▸ 答案：指**欠着这笔债，以后每次改动都要多付的成本**——多改几处、多测几轮。

**Q3** 用户很少、宕机半天也没人投诉的内部系统，要做缓存和负载均衡吗？

▸ 答案：**可以不做**，架构只解决复杂度；但**数据可靠性要做**——数据丢了就是事故，与用户量无关。
