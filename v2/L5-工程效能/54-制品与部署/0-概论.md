## 5 分钟入门：先记住这 8 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **制品** | 能直接上线的成品字节 | 封好箱、贴封条的整箱货 |
| **digest** | 按内容算的哈希，变一字节就变 | 按特征算出的编号，不是自起的名字 |
| **tag** | 给人看的可变别名 | 通讯录里的“妈”，换号还叫妈 |
| **镜像仓库** | 存放分发制品，管谁能推谁拉 | 有门禁和出入库单的仓库，不是网盘 |
| **期望状态** | 写下的“应该跑成什么样”，可 diff | 装修效果图，工头照它比对 |
| **部署编排** | 把期望写成声明，交给控制器收敛 | 空调按设定温度自己开关 |
| **环境一致性** | 同制品 + 同编排 + 只差白名单 | 两家分店同配方，只营业时间不同 |
| **配置注入** | 环境的值从外送进进程 | 洗衣液和水温每次自己加 |

> 记住 **“身份看内容，不看名字”**，其余都是推论。

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| “tag 一样就是同一份东西” | tag 可重指向；只有 digest 由内容算出，晋升时比对的是它 |
| “环境一致性就是把配置抄成一样” | 抄一样不等于差异可枚举；列不出来的差异，就是下次“生产挂了” |
| “部署就是把命令发到机器上” | 发完就结束，没人对账；编排要能收敛，也要答得出失败怎么退 |

## 读完自检（入门级 3 题）

**Q1** 两个环境跑着同一个 tag，怎么判断跑的是不是同一份字节？

▸ 答案：比对 digest。tag 只是别名，可被重指向；digest 由内容算出。

**Q2** 部署脚本返回成功，能说明服务可用了吗？

▸ 答案：不能。脚本只把期望写下去，实例可能一个都没起来，要靠收敛与健康门禁。

**Q3** 测试环境通过、生产仍出问题，最先查哪一类差异？

▸ 答案：白名单之外的差异：digest 是否相同、编排定义是否同一份、参数是否只在白名单内。
