# 4.4 Make / Buy / Reuse 决策

## 一句话

> 自建、买、复用不是 “技术偏好”，而是**三年 TCO 的比较**：自建付人力与维护，买付订阅与绑定，复用付适配与协调——算清三笔账，再谈 “我们想不想自己做”。

## 三年 TCO 实测（示例口径）

按 “初始 + 月成本 × 36” 估算，单位万元：

| 能力 | 自建 | 买 | 复用（内部平台） |
|---|---|---|---|
| 通用（HR/报销） | **740** | **318** | 128 |
| 差异化（推荐） | **840** | **960** | 420 |

两个结论：① **通用能力买最省**（自建 2.3 倍于买）；② **差异化能力买到第三年反而更贵**（订阅随规模涨，且定制受限）——这正是 “核心域必须自建” 的量化版本。

```python
def tco(init, monthly, years=3): return init + monthly*12*years
print(tco(200,15), tco(30,8), tco(20,3))   # 740 / 318 / 128
```

## 三个方案的隐藏成本

| 方案 | 显性成本 | 隐性成本 |
|---|---|---|
| 自建 | 人力、服务器 | 招聘、离职风险、长期维护、合规 |
| 买 | 订阅费 | 绑定、涨价、定制受限、数据迁移 |
| 复用 | 适配开发 | 协调成本、平台优先级、被上游改挂 |

判据：**隐性成本往往在第二三年才显现**，TCO 至少要算 3 年，并把 “退出成本” 单列。

## 决策表

| 你的情况 | 选择 |
|---|---|
| 通用能力、有成熟 SaaS | 买 |
| 差异化核心、变更频繁 | 自建 |
| 公司内已有平台且能力匹配 | 复用 |
| 合规要求极高（数据不能出域） | 自建/私有化 |
| 一次性/低频需求 | 买或外包，别自建 |

## 反模式

| 反模式 | 后果 |
|---|---|
| 只算 “第一年成本” | 第二年订阅涨价/维护成本暴露 |
| 把 “自建” 当技术能力证明 | 核心域反而投入不足 |
| 买完不做退出方案 | 被绑定，迁移成本高到不敢换 |
| 复用不考虑平台优先级 | 你的需求永远排在平台后面 |
| 忽略合规与数据归属 | 后期整改成本远超省下的钱 |
| 不记录决策依据 | 换人后无法解释 “为什么自己做” |

## 三条铁律

> 🔑 **核心域自建、通用域买**；用 TCO 而不是偏好决策。

> 🔑 **必须算 3 年 + 退出成本**。

> 🔑 **决策要留依据与复核点**（见 [4.6 决策框架与决策记录](4.6-决策框架与决策记录.md)）。

## 自检

**Q1** 为什么 “通用能力” 自建的 TCO 会高这么多？

▸ 答案：因为自建要承担**全生命周期成本**：开发、招聘、值班、升级、合规审计；而通用能力（HR、报销）已有成熟产品，边际成本低。本例 740 vs 318，差在 “持续人力” 而不是 “初始投入”。

**Q2** 为什么 “差异化能力” 买到第三年反而更贵？

▸ 答案：因为 SaaS 的订阅通常随**用量/席位**增长，且定制要额外付费；而差异化能力往往需要深度定制与快速迭代，买来的系统跟不上节奏，最终 “买 + 定制 + 补丁” 的总成本超过自建。

**Q3** “复用” 为什么不是免费的？

▸ 答案：因为要付**适配与协调成本**：接入平台要改代码、对齐规范；平台有自己的优先级，你的需求可能排队；平台升级还可能破坏你的用法。复用的前提是 “能力匹配 + 平台有承诺”。

**Q4** TCO 里为什么要单列 “退出成本”？

▸ 答案：因为绑定成本往往在**迁移时才爆发**：数据导出格式、接口兼容、重新培训。把退出成本写进决策，能避免 “因为迁移太贵，所以只能继续续费” 的被动局面。

**Q5** 什么情况下 “买” 反而不划算？

▸ 答案：当需求**高度定制、变更极快、或数据不能出域**时：SaaS 的标准化能力跟不上，定制费与合规成本会超过自建。此时 “买” 只是把成本推迟，而不是消除。

**Q6** “复用内部平台” 和 “买 SaaS” 的本质区别？

▸ 答案：复用是**组织内协作**（可以提需求、可以影响路线图），买是**市场交易**（只能接受产品路线）。复用的风险是 “平台优先级”，买的风险是 “厂商绑定与涨价”。

**Q7** 怎么让这个决策可复核？

▸ 答案：记录四样：**假设**（人力单价、订阅涨幅、用量增长）、**TCO 模型**（可重算的脚本）、**触发复核的条件**（如 “订阅年涨幅 > 15% 或用量翻倍”）、**退出方案**。没有假设与触发条件，决策就变成 “一次性的政治结论”。
