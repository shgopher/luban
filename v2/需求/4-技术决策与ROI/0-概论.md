## 5 分钟入门：先记住 8 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **ROI** | 投进去的钱和人，换回多少业务结果 | 花一笔钱改厨房，看每月少下多少馆子 |
| **收益模型** | 指标动了多少 × 每个点值多少钱 | 体温计读数，不是“感觉有点热” |
| **TCO** | 买价之外，还算迁移、双跑、培训、维护、退出 | 买车看落地价，更看油费 |
| **评估维度** | 先定比什么、各占几分，再打分 | 招标先写死规则 |
| **四环** | 能不能用，看证据等级不看热度 | 药品的处方/临床/禁用 |
| **ADR** | 一页纸写清选项、理由、推翻条件 | 病历本，换医生也看得懂 |
| **止损条件** | 事先写好的“什么信号停”，且可观测 | 安全气囊的碰撞传感器 |
| **硬门槛** | 先淘汰不满足底线的，再比综合分 | 招聘先卡学历，再看排名 |

```
  念头：我们该不该上这个东西？
              │
              ▼

              │
              ▼

              │
              ▼
  ⑤ 谁拍、留什么字据？（4.6 框架 + 记录）
              │
              ▼
  ⑥ 万一错了靠什么停？（4.7 可观测止损）
              │
```

- 上半段（4.1–4.4）问“值不值”，下半段（4.5–4.8）问“怎么定、怎么退、谁来做”；
- 闸门答不上就停在原地；产物是最后那行字据：结论会过时，记录不会。

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| “ROI 就是算钱，越细越可信” | 算得细不等于算得全；先不漏项，再谈精度 |
| “选型要选最强的那个” | 选的是**约束下总代价最小、退出成本可控**的那个 |
| “风险清单写完就做完了” | 没有可观测触发条件的清单只是决心 |

## 读完自检（入门级 3 题）

**Q1** 有人说“重构把接口耗时砍掉一大截，收益巨大”。按 4.1，还缺什么？

▸ 答案：缺**指标值多少钱**、**覆盖面**、**兑现率与持续期**；耗时只是乘数。

**Q2** 为什么 4.3 要求权重写在打分之前？

▸ 答案：否则先有偏好再挑维度；权重先定，评审才吵标准。

**Q3** 团队说“先自建，两年后再看”，按 4.4 和 4.7 还欠哪两句？

▸ 答案：4.4 欠三年总代价的对比；4.7 欠**可观测的止损条件**——什么指标到什么值、看多久，就认错。
