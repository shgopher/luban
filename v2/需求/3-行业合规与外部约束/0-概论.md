# 第 3 章 行业合规与外部约束 · 概论

## 一句话

> 这一章回答：法律与行业标准给系统划了哪些不能谈判的线。答案是：**先分类分级，再定控制项，最后留证据**。

## 5 分钟入门：先记住这 8 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **等保** | 按出事后果分五级，各配清单 | 住宅楼与化工厂，消防不同 |
| **控制项** | 每条要求翻译成做什么 + 证明 | 考驾照：会开车 + 学时 |
| **个人信息** | 能对应到某个具体的人 | 写你名字的快递单 |
| **敏感个人信息** | 泄露后让人受损 | 病历本、身份证 |
| **合法性基础** | 收集前先说清凭什么 | 进门先敲门，不是后补票 |
| **最小必要** | 只收非收不可的字段 | 住酒店只登记身份证 |
| **数据出境** | 数据到境外，或境外能访问 | 户口本寄到国外 |
| **审计日志** | 谁、何时、做了什么，且改不了 | 盖骑缝章的账，撕页留痕 |

## 一张图：这章的骨架

```
外部约束：网安法 / 个保法 / GDPR / 行业规范
                │
                ▼
 ① 定级（3.1）─ 定控制项与测评周期
                │
                ▼
 ② 盘点字段：哪些是个人信息、哪些敏感（3.2）
                │
   ┌────────────┼────────────┬──────────────┐
   ▼            ▼            ▼              ▼
 ③合法性+     ④出境判定   ⑤行业规范     ⑥审计取证
  最小必要     类别+规模   底线之上       五要素+防篡改
  +可追溯      三选一(3.3) 还差多少(3.4)  →证据链(3.5)
   (3.2)         │            │              │
   └────────────┴────────────┴──────────────┘
                │
                ▼
  能拿给测评 / 监管 / 法庭
```

- 上半段读法条，下半段改系统；顺序不能反。
- ③④⑤ 都从“盘点字段”长出来。
- 终点是**能拿出来的证据**，不是“合规”。

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| “合规是法务的事” | 级别定控制项、分级定脱敏、出境定数据放哪，都落在架构 |
| “买了 WAF 就合规” | 设备只证明有能力；评的是控制项 + 证据 |
| “先上线，出事再补” | 证据日常产生，补不出来；定级低责任重 |

## 读完自检（入门级 3 题）

**Q1** 有人说“我们系统小，定个二级就行”。问题出在哪？

▸ 答案：级别按**被破坏后侵害谁、多严重**定，不按省事挑。定低了，控制项就没做。

**Q2** 产品要读通讯录找好友，法务问“必要性在哪”。这对应什么？

▸ 答案：**最小必要**。要说清为什么非全量不可、能否只本地比对。

**Q3** 数据放在境外云上，为什么不能只问“网络通不通”？

▸ 答案：出境先过法律判定：**类别与规模**决定走评估、合同还是认证；路径没定，通不通无意义。
