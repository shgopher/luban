## 5 分钟入门：先记住这 8 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **故障模型** | 约定坏法有几种、最坏多坏 | 保险条款先写清保哪些灾 |
| **崩溃故障** | 节点直接不说话 | 电话突然断线，没声了 |
| **遗漏故障** | 该到的没到，或到了两遍 | 快递丢件，或同一单发两回 |
| **时序故障** | 没死，但慢得离谱 | 电梯卡在楼层之间，人还在 |
| **拜占庭故障** | 会主动说错话 | 会上有人故意报假数字 |
| **FLP 不可能性** | 完全异步且允许崩溃时，没有又安全又一定终止的确定性共识 | 没截止时间的会，散不了 |
| **故障检测器** | 靠超时猜死活的哨兵，快与准不可兼得 | 保安隔几分钟巡一次房 |
| **GST（部分同步）** | 网络终将好到延迟有上界的时期 | 堵车散了，车程才可估 |

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| “FLP 证明共识做不了” | 只在**完全异步 + 可能崩溃 + 确定性**下成立；换掉假设，Paxos/Raft 都能跑 |
| “超时调短就更快发现故障” | 误判的代价是无谓切主、迁移与告警，快与准只能选一点 |
| “拜占庭容错就是多复制几份” | 要 **3f+1** 个副本再加签名等机制；拿崩溃方案解拜占庭等于没解 |

## 读完自检（入门级 3 题）

**Q1** 一个节点几秒没回心跳，能断定它死了吗？

▸ 答案：不能。异步模型里慢与死不可区分，超时只是猜疑；检测器只能“最终不误判”，判死要按误判代价定价。

**Q2** FLP 说共识不可能，为什么 Raft 还能用？

▸ 答案：FLP 前提是完全异步、允许崩溃、确定性。Raft 默认部分同步，靠超时选主，只承诺 GST 后收敛。

**Q3** 为什么拜占庭故障不能照抄崩溃方案？

▸ 答案：崩溃只是不说话，多数派加重试能兜住；拜占庭会主动说谎，要 3f+1 个副本加签名才分得清。
