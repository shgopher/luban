## 5 分钟入门：先记住这 7 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **墙钟** | 带日期，会漂、会被拨回 | 谁都能去拨的挂钟 |
| **单调时钟** | 只往前走、不认日期，用来测耗时 | 秒表：只累计秒数 |
| **happened-before** | a → b 当且仅当有一条消息链 | 快递轨迹：经过的站点必晚于寄出 |
| **Lamport 时钟** | 只增不减的整数，有因果必有序 | 取号机：5 号先于 7 号，两个网点各发号 |
| **向量时钟** | 一个计数器向量，能分出先后还是并发 | 每人一本签到簿，记着你的次数 |
| **HLC** | 一对（物理时间, 逻辑计数），单调又贴近真实时间 | 带日历的秒表，拨不回去 |
| **TrueTime** | 只给误差区间，提交时等过区间 | 站牌写“3 到 5 分钟到”，等满再走 |

> 记住一句：**测耗时用单调钟，定顺序用逻辑钟，要真实时间就交区间。**

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| “时间戳更小就是先发生” | 墙钟会漂、会被 NTP 拨回，跨机比较不成立；反序列化后也没单调分量 |
| “并发就是同时发生” | 并发是**因果上不可比**，可以相隔很久，只看有没有消息链 |
| “有了原子钟，逻辑时钟就没用了” | 原子钟只是把误差区间做小，不是零；TrueTime 也要等区间过去 |

## 读完自检（入门级 3 题）

**Q1** 两台机器各有一条日志时间戳，A 比 B 晚一点。能说 B 先写吗？

▸ 答案：不能。墙钟会漂、会被拨回，跨机比较不成立；定先后要用版本号或逻辑钟。

**Q2** Lamport 时间戳 a 比 b 小很多，能推出 a → b 吗？

▸ 答案：不能。Lamport 只保证“若 a → b 则号更小”，反过来不成立；并发事件号可差很远。要判断是否并发得用向量时钟。

**Q3** 两个向量互有大小（各自在某一维更大），说明什么？HLC 能得出同样结论吗？

▸ 答案：说明两个事件**并发**——没有消息链相连，不是“同时发生”。HLC 只是一对数，能定先后，却证明不了不可比。
