## 5 分钟入门：先记住这 8 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **RPO** | 最多能丢多少数据 | 云同步后拍的照片，掉水里就没了 |
| **RTO** | 最多能停多久 | 跳闸后从一片黑到能做饭 |
| **全量 / 增量 / 差异** | 三种备份的成本结构 | 抄笔记：整本重抄 / 补新增 / 补改页 |
| **冷备 / 温备 / 热备** | 恢复时还有多少活要人干 | 灭火器：锁仓库 / 挂墙拔销 / 喷淋自开 |
| **两地三中心** | 同城两个中心加异地一个 | 同城两间办公室，外地一个仓库 |
| **多活** | 多机房同时接活，一个没了照跑 | 两家分店同开，一家关门客人拐另一家 |
| **单元化（Set 化）** | 用户的请求和数据锁进自闭环单元 | 小区自带配电房，停一片不影响别片 |
| **脑裂 / fencing** | 两个主都以为自己是主，用围栏挡旧的 | 两人各拿一份遗嘱，只认那枚印章 |

> 主线一条：**先定丢多少、停多久，再决定钱花在哪**。

## 一张图：灾备预算阶梯

灾备不是“要不要做”，是“爬到第几级”。每上一级，成本按倍数涨、年停机掉一个量级——**先看这一级每小时停机要多少钱，再决定爬不爬**。

```text
成本     年停机     这一级买到什么                              细节
5.2×  ┤  0.04h   三地五中心：地域级灾难用户几乎无感            36.4
3.1×  ┤  0.1h    两地三中心：城市级灾难还能恢复                36.4
2.1×  ┤  2.0h    同城双活：单机房故障，分钟级切走              36.4
1.0×  ┤  34.8h   单中心 + 异地冷备：数据在，业务停             36.2 / 36.3
       └──────────────────────────────────────────────────
  ↑ 每一级之前先过 36.1 的两个数：丢多少（RPO）、停多久（RTO）
  ↑ 每一级之后都要验收：切过去不能乱（36.6）、掐表跑一遍（36.7）
```

| 从 → 到 | 多花 | 年停机减少 | 每减少 1 小时/年停机要付 | 该不该爬 |
|---|---|---|---|---|
| 单中心 → 同城双活 | +1.1× | 32.8 h | **0.03×** | 几乎总该爬：这是整条阶梯最便宜的一步 |
| 同城双活 → 两地三中心 | +1.0× | 1.9 h | 0.53× | 只有“城市级灾难”写进合同才爬 |
| 两地三中心 → 三地五中心 | +2.1× | 0.06 h | **≈30×** | 悬崖：只有“每分钟停机按金额计损”才爬 |

> 🔑 **单价口径**：`成本增量 ÷ 年停机减少量`，数字取自 [36.4](36.4-两地三中心与多活.md) 的拓扑账，按小时折算。三层之间差 1000 倍——这就是“最后半个 9 最贵”的定量版本。

**单元化不在这条阶梯上**，它是正对阶梯的一个杠杆：[36.5 单元化 / Set 化架构](36.5-单元化-Set化架构.md) 不降年停机，降的是“一次故障砸到多少人”（1/N）。代价是 1.6 倍基础设施 + 40–120 人月，且要先过五道门：① 有真实跨地域写冲突 ② 回本 ≤ 24 个月 ③ 跨单元请求 < 90% ④ 页面 P99 在预算内 ⑤ 有单元级灰度与演练。第一门不过，就别为隔离付单元化的钱。

- 爬之前先算这一级每小时多少钱：**0.03× → 0.53× → 30×**，同一件事贵 1000 倍。
- 阶梯买的是**停机时间**，不买**数据错乱**：切过去的一致性由 36.6 兜，能不能切由 36.7 证明。
- 三条独立的钱：备份买数据、预置买人、拓扑买整机房。只投一笔，另外两笔会把 RTO 拖回去。

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| “有备份就有灾备了” | 备份只解决数据还在；没有预置环境和恢复流程，RTO 照样被拖长 |
| “多活就是多建几个机房” | 门槛不是机房数量，是冲突方案、流量调度和演练能力 |
| “切换前多同步几次就不丢数据” | 要堵的是脑裂和位点，多同步只是把窗口推小 |

## 读完自检（入门级 3 题）

**Q1** 同事说“备份买了，灾备就没问题了”，漏了什么？

▸ 答案：漏了“停多久”那一半。备份只保证数据还在，RTO 由预置环境与切换流程决定。

**Q2** 冷备和热备的差别，是硬盘快慢吗？

▸ 答案：不是，是**恢复时还有多少活要人干**：冷备要人装机导数据，热备自动切。杠杆是自动化。

**Q3** 什么时候只做两地三中心、不上多活就够？

▸ 答案：能接受“机房没了先停一段再恢复”时就够。成本随层数翻倍，门槛在冲突与演练。
