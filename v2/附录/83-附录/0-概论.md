## 5 分钟入门：先记住这 7 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **防歧义清单** | 只收「一词两义」和「说错就露怯」的词 | 菜谱的「盐少许」得改成 3 克 |
| **邻居** | 每个词要说清和最容易混的那个差在哪 | 两种药名只差一个字，护士得指出差哪 |
| **前提** | 结论成立的条件，换掉条件结论作废 | 退烧药说明书：38.5℃ 以上才吃 |
| **出处** | 这结论来自哪篇文献、哪一年 | 体检报告印着哪台机器、哪天 |
| **修正记录** | 它在工程里被谁改过、改成什么样 | 老菜谱旁的铅笔字：火减半 |
| **淘汰条件** | 什么情况下该把它换掉 | 租房合同里那条退租条款 |
| **带走的产出** | 读完留下一页能被评审的结论 | 饭端上桌，翻菜谱不算做过 |

> 七条其实是一条：**每份清单都要写清边界**。

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| 「附录是正文读完才翻的」 | 它是**查证入口**：读第一章被一个词卡住就该来查，等读完再查，前面已经用错了 |
| 「工具清单就是排行榜，选第一名」 | 清单不是排行榜，答的是**「在什么约束下选谁」**；给不出淘汰条件的推荐本质是广告 |
| 「学习路径就是从第 1 章读到第 83 章」 | 路径以**你手上那个决策**为起点，前后各取三步 |

## 读完自检（入门级 3 题）

**Q1** 一个词「感觉挺熟」，但说不出它和隔壁那个差在哪，算懂了吗？

▸ 答案：不算。术语表每条都要给「最容易混的邻居」，说不出差别就是没定义。

**Q2** 有人推荐一个工具，只说了它多快多流行，没说什么？

▸ 答案：没说淘汰条件——给不出淘汰条件的推荐，本质是广告。

**Q3** 手上压着一个决策，应该从第 1 章开始读吗？

▸ 答案：不必。以那个决策为起点，前后各取三步；读完产出一页能被评审的结论。
