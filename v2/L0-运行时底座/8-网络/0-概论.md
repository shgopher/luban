## 5 分钟入门：先记住这 8 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **TCP** | 在"尽力送到"的 IP 上，用确认与重传换出可靠流 | 挂号信：没回执就再寄 |
| **RTT** | 一个来回的时间，握手与等确认都按它算 | 问一句、等一句 |
| **TIME_WAIT** | 主动关闭方等满 60 秒，让残包死透 | 挂电话后等回音散掉 |
| **TTL** | 一条 DNS 记录在各层缓存里还能活多久 | 便签上的有效期 |
| **TLS 证书** | 由第三方签过字的身份证 | 门禁卡：只认签发方 |
| **VPC** | 自己划的逻辑机房，网段几乎改不了 | 圈一块地，围墙很难挪 |
| **NAT** | 改写地址与端口，并记住映射 | 前台：外线只留一个号 |
| **四层 / 七层** | 只看 IP 与端口转发 vs 拆开请求再转发 | 看信封地址 vs 拆信看内容 |

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| "带宽够就不会慢" | 吞吐被窗口与 RTT 卡着；慢启动、Nagle 与延迟确认、排队会叠上去 |
| "TIME_WAIT 太多是内核 bug，调小就好" | 省的是端口，赔的是残包串进新连接 |
| "换 HTTPS 或上七层就更安全" | TLS 管加密与验身份，不管越权；七层多付 CPU、一跳延迟和有状态代理 |

## 读完自检（入门级 3 题）

**Q1** "带宽升了一倍还是慢"，先看哪两个量？

▸ 答案：**RTT** 与**窗口（cwnd / rwnd）**。吞吐约为 `min(cwnd, rwnd) / RTT`；窗口小、来回久，带宽再大也填不满。

**Q2** TIME_WAIT 出现在哪一端？为什么不能一关了之？

▸ 答案：主动关闭的一端。等满 60 秒让残包死透，否则会串进复用同一地址端口的新连接。

**Q3** 公网入口什么情况下必须上七层？

▸ 答案：需要看请求内容时，按路径或头灰度、鉴权、按请求重试。只把包送到机器，四层更便宜。
