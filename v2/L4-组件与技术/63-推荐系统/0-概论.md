## 5 分钟入门：先记住这 8 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **召回** | 从千万条捞回上千条相关的 | 撒大网，先保证鱼在网里 |
| **排序** | 给每条候选打“会不会点”的分 | 面试后打分排名 |
| **重排** | 再加去重、多样性、业务位 | 排好座次再调座位 |
| **特征** | 模型输入，如近 7 天点击 | 相亲前递的资料卡 |
| **延迟预算** | P99 里每层能花多少毫秒 | 传菜时限，凉热菜各几分钟 |
| **冷启动** | 新用户新内容没数据怎么推 | 新店先做小份试吃 |
| **A/B** | 随机分两组，只改一个变量 | 两家分店只换一道调料 |
| **反馈回路** | 用自己推的数据训练自己 | 只吃自己做的菜，口味越来越窄 |

```
                    │  能看        63.6 别越推越窄
                    ▼
   线上 A/B 判决 ──▶ 曝光点击日志回流 ──┐
       63.5  先看样本量                │
        └──────── 下一轮训练 ◀─────────┘
   横贯：63.1 延迟 · 63.4 冷启动 · 63.7 推拉
```

- 竖看是**一条漏斗**：候选越筛越少，模型越换越贵；每段目标不同，**没有单一指标能衡量整条漏斗**。
- 横看是**一条回路**：曝光变点击，点击又变训练数据——既是燃料，也是偏差来源。

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| “推荐系统就是一个排序模型” | 模型只占精排一段；召回定上限，重排定能否看，特征定有没有米 |
| “离线指标涨了就该上线” | 离线只够筛掉明显差的，最终靠线上 A/B，门槛是样本量 |
| “推得越准越好” | 越准越容易收窄：位置红利加反馈回路，多样性是约束 |

## 读完自检（入门级 3 题）

**Q1** 为什么不能拿重模型直接给千万候选打分？

▸ 答案：算不起也等不起。重模型单条毫秒级，乘上千万要几十分钟；先用便宜召回压到千级，贵模型只算少量候选——**漏斗的形状就是成本约束**。

**Q2** 离线 NDCG 涨了 8%，线上 CTR 没动，先查什么？

▸ 答案：先查**特征口径**：两边算的不是同一个数，一漂就离线涨线上不涨；再看样本量。

**Q3** 只看点击率优化，半年后列表越来越窄，谁在起作用？

▸ 答案：**位置偏差加反馈回路**：靠前曝光点击多，模型把它当吸引力，越推越窄；没曝光的内容永远没数据。只能靠重排的多样性约束与冷启动的探索预算对冲。
