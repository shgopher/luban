## 5 分钟入门：先记住这 8 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **主体 ID** | 不可变的人编号，改名换号都不变 | 身份证号，不是手机号 |
| **权威源** | 唯一有权说“他存在 / 已离职”的系统 | 户籍派出所 |
| **认证** | 证明“你是你” | 刷一次门禁卡 |
| **授权** | 判断“你能做什么” | 同一张卡开不了别人家的门 |
| **IdP** | 只登录一次，别的应用信它签的断言 | 机场一次安检，全场通行 |
| **断言 / 令牌** | 带签名、有有效期的通行证 | 演唱会手环，剪断作废 |
| **权限中心** | 谁能对什么做什么，写成数据而非散落的 `if` | 一栋楼的钥匙总表 |
| **租户** | 同一套系统里的一个客户，数据互不可见 | 公寓里不同的住户 |

> 认证答“你是谁”，授权答“你能干什么”，令牌管“还有效多久”。

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| “SSO 就是一个统一登录页” | 登录页只是壳，要做对的是断言格式、验签规则、登出；登出常只能登出当前应用 |
| “用户表有 role 字段就是权限中心” | 权限要是可评审、可审计、可热更新的策略数据，矩阵由工具生成、能 diff |
| “租户 ID 进 SQL 的 `WHERE` 就隔离了” | 还要进每次判定、每个缓存键、每条消息，漏一处就泄漏 |

## 读完自检（入门级 3 题）

**Q1** 认证与授权各回答什么？SSO 解决哪个？

▸ 答案：认证答**“你是谁”**，授权答**“你能对什么做什么”**。SSO 属前者：IdP 签发断言、应用验签，只管登录，登录成功不等于有权限。

**Q2** 为什么租户 ID 只写进 SQL 的 `WHERE` 不够？

▸ 答案：请求路径上还有鉴权判定、缓存键、异步消息，各带一份身份上下文；漏一处就读到别人的缓存。

**Q3** 令牌没过期，为什么还可能要求重新登录？

▸ 答案：过期只是时间条件；离职、封号、改密码时需要一份可作废的登录态记录。
