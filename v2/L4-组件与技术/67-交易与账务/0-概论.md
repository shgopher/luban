## 5 分钟入门：先记住这 8 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **单据** | 业务意图：订单、支付单、退款单 | 点菜单 |
| **状态机** | 这笔交易能走到哪、不能走到哪 | 登机牌：值机后不能退回未值机 |
| **流水** | 实际发生了什么，只增不改 | 银行流水账 |
| **幂等键** | 同一笔业务重复提交时的“身份证” | 取号票：一个号只办一次 |
| **挂账** | 差异先记账、待核查 | 失物招领柜 |
| **复式记账** | 有借必有贷，借贷必相等 | 天平两边同时加砝码 |
| **借贷平衡** | 分录校验：借方合计 = 贷方合计 | 账本自查 |
| **资损** | 真金白银的损失，不只是“数据不一致” | 收银台少了钱 |

> 记住：**单据管意图、状态机管进度、流水管事实**；其余问题都能挂到这三件事上。

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| “订单表就是账” | 订单是交易单据，账务是资金事实；退款、手续费、分账都表达不了 |
| “对账就是比总额” | 总额会把方向相反的误差抵消，必须逐笔比 |
| “资损离我们很远” | 重复退款、汇率取错、对账漏单，任何一条都能吃掉几个月利润 |

## 读完自检（入门级 3 题）

**Q1** 一笔支付为什么需要“支付单”，不能只用订单？

▸ 答案：因为一个订单可能多次支付（换渠道重试）、也可能部分退款；订单记录“买什么”，支付单记录“用哪个渠道付了多少、什么状态”。合并成一张表，多次支付与部分退款就无法表达。

**Q2** 支付超时该落什么状态？

▸ 答案：落“未知/处理中”，不是失败。超时只说明没收到响应，下游可能已成功；当失败处理会让用户重试并可能重复扣款，正确做法是查询渠道或等回调，再落最终态。

**Q3** 对账发现“渠道有、平台无”，该做什么？

▸ 答案：这是长款，按渠道流水补单（补记平台侧），并追查回调为什么丢失；不能“忽略”或“直接改余额”，否则账实永远对不上。
