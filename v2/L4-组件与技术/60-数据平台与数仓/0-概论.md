## 5 分钟入门：先记住这 8 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **分层** | 按「谁生产、谁消费、谁担保 SLA、谁付账单」切四份契约 | 餐厅的采购、后厨、传菜、前台 |
| **ODS** | 贴源层：原始数据原样接入，不做加工 | 驿站暂存，原箱不拆 |
| **DWD** | 明细层：清洗去重后「一单一行」的事实 | 零件按型号分拣、贴标签 |
| **DWS / ADS** | 一个只做聚合，一个只定指标口径 | 先对账，再定退款算不算营业额 |
| **湖仓一体** | 开放文件格式 + 表格式元数据 + catalog，把 ACID 与时间旅行搬到对象存储 | 既堆散货，也能按目录借还 |
| **元数据** | 描述「有哪些表、谁负责、改动会炸到谁」 | 图书馆的检索目录 |
| **质量门禁** | 把「可接受的数据」写成契约，进下一层前阻断 | 出厂质检，当场拦下 |
| **行 / 列权限** | 让查询引擎在返回结果前过滤不该看的行列 | 同一张工资表只看自己那行 |

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| 「分层就是把组件摆一排」 | 层是责任边界，由元数据 + 依赖规则定义；多一层就多一次延迟、一份存储 |
| 「湖仓 = 湖 + 仓拼起来」 | 开放文件格式 + 表格式元数据 + catalog 把数据库能力搬到对象存储；代价是元数据成新故障点 |
| 「权限就是给表授权」 | 表权限只挡入口；行/列权限才决定数据出得去多少，且须引擎执行 |

## 读完自检（入门级 3 题）

**Q1** 同事说「组件都齐了，平台早建好了」，怎么反驳？

▸ 答案：组件不等于层。判断层只问：独立输入输出、独立 SLA、明确 owner——缺一即装饰。

**Q2** 为什么 ODS 不能直接跳到 ADS 出报表？

▸ 答案：ODS 只贴源、DWD 一单一行、DWS 只聚合、ADS 只口径；跳过中间层，清洗与口径就抄进每张报表，复用变复制。

**Q3** 有表权限，却看到别的租户的数据，问题在哪？

▸ 答案：表权限只挡入口。行/列权限要由查询引擎执行，不能靠应用加 WHERE。
