# 第 75 章 供应链与物流架构 · 概论

## 一句话

> 供应链系统只回答四个问题——**备多少、从哪发、怎么拣、何时到**，再加一条“退回来怎么算账”；四条主线各有一组可算的数（预测误差、ATP、行走距离、ETA），架构好坏看这些数能不能被同一个库存事实源串起来，而不是看有没有上 TMS/WMS。

## 5 分钟入门：先记住这 8 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **需求预测** | 用历史与周期估未来销量 | 看天气预报决定带不带伞 |
| **安全库存** | 为误差尾部准备的缓冲，`z×σ×√LT` | 冰箱里多存一天的菜 |
| **再订货点** | 库存位置低于它就补货的那个数 | 油表亮灯去加油 |
| **ATP** | 可承诺量 = 库存位置 − 预占 − 安全库存 | 餐厅“还能接几桌” |
| **拆单** | 一个订单拆成多个包裹/发货仓 | 一道菜分两个窗口取 |
| **波次** | 多张订单合并成一次拣选任务 | 拼车一次送多单 |
| **ETA** | 预计送达时间，随轨迹事件更新 | 打车的“预计 8 分钟到” |
| **逆向** | 退货、换货、维修、拒收与赔付 | 超市的退货窗口 |

> 记住：**计划管“备多少”，履约管“从哪发”，仓储管“怎么拣”，运输管“何时到”，逆向管“退回怎么算账”**。

## 一张图：这章的骨架

```
用户下单
   │
   ▼
75.1 计划与库存：预测 → 补货 → 安全库存（每个仓有多少货）
   │        └─ 牛鞭：需求波动往上游放大 10.18 倍
   ▼
75.2 履约与订单路由：拆单 / 寻源 / 承诺 / ATP 分配（从哪发、几天到）
   │        └─ 单均总成本 62.2 元 vs 66.7 元，但前者 16 单不履约
   ▼
75.3 仓储 WMS：入库 → 库位 → 波次 → 拣选 → 盘点（怎么拣出来）
   │        └─ 20.4 单/人时 → 87.0 单/人时
   ▼
75.4 运输 TMS 与 ETA：调度 → 轨迹 → 时效预测（在路上、何时到）
   │        └─ 95% 承诺 100.1h → 79.7h
   ▼
75.5 逆向与异常：退货 / 换货 / 异常件 / 赔付（退回怎么算账）
          └─ 分级处置比全部回中心仓少损失 28%
```

- 竖看是**一单货的完整生命周期**；横看是**一条统一纪律**：所有环节用同一个库存位置口径（在手 + 在途 − 已分配），ATP 再减预占与安全库存。

## 本章要解决的 7 个真问题

| 问题 | 在哪一节 | 一句话答案 |
|---|---|---|
| 预测更准了，库存为什么没降 | [75.1](75.1-供应链计划与库存.md) | 库存由误差尾部 × 补货周期决定，不由均值精度决定 |
| 需求波动为什么越往上游越大 | [75.1](75.1-供应链计划与库存.md) | 牛鞭效应：4 级链累计放大 10.18 倍，信息共享后 4.96 倍 |
| 一单拆成两包，到底更贵还是更便宜 | [75.2](75.2-履约与订单路由.md) | 拆单费 + 首重 vs 远仓干线 + 超时罚，本节只差 0.7 元/单 |
| 有库存却卖超了 | [75.2](75.2-履约与订单路由.md) | 现存量 ≠ ATP：30 件预占被重复承诺，实测超卖 10 单 |
| 仓里人效上不去 | [75.3](75.3-仓储WMS.md) | 80% 时间在行走：ABC 降 26%，波次降 82% |
| 客户问“我的件几点到” | [75.4](75.4-运输TMS与轨迹ETA.md) | 分段 + 轨迹更新：MAE 30.8h → 7.2h，95% 承诺 100.1h → 79.7h |
| 退货越处理越亏 | [75.5](75.5-逆向与异常.md) | 分级处置少损失 28%，货值 42 元是仅退款分界线 |

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| 「供应链 = 采购 + 物流」 | 采购决定进价，架构决定备多少、放哪里、怎么发、退回怎么算；同样进价，策略不同净损失差 28% |
| 「上 WMS/TMS 就解决了」 | 系统只是载体；库存位置口径、拆单判据、分级规则、ETA 更新点错了，上什么系统都是把错误自动化 |
| 「退货率低不用管逆向」 | 8% 在 10,000 单上就是 800 单、4.4 万元净损失；不做分级处置就一直在漏 |

## 读完自检（入门级 3 题）

**Q1** 计划、履约、仓储都在算库存，为什么必须用同一个“库存位置”口径？

▸ 答案：否则计划按现存量补货、履约按现存量承诺、仓储按现存量拣货，在途与预占被重复计算：计划重复下单、履约超卖、仓储拣不出货。库存位置 = 在手 + 在途 − 已分配；ATP = 库存位置 − 预占 − 安全库存（[75.2](75.2-履约与订单路由.md)）。

**Q2** 一单从下单到签收，哪个环节最容易“看不见”？

▸ 答案：运输段。仓内有 WMS、下单有订单系统，运输轨迹依赖承运商回传，缺失与延迟都不可控；所以 ETA 必须分段并随事件更新，用“事件超时未更新”作异常判据（[75.4](75.4-运输TMS与轨迹ETA.md)）。

**Q3** 只能先做一件事降本，先做哪件？

▸ 答案：先统一**库存位置口径**。它一次影响补货、承诺、拣货三段的正确性，改动在数据层、不动作业流程；其次才是波次与逆向分级这类局部优化——口径不统一时，局部优化会被重复计算抵消。
