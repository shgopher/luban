## 5 分钟入门：先记住这 6 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **决策点** | 在哪个环节做判断（登录/支付/领券/发布） | 小区几个门，各配几个保安 |
| **时延预算** | 决策必须多快给出 | 安检不能让人排一小时 |
| **名单** | 已知好/坏人的清单 | 门口的黑名单 |
| **实时特征** | 近 N 分钟的行为统计 | 最近五分钟进出几次 |
| **设备指纹** | 这台设备的“长相” | 看脸认人，不看身份证 |
| **误杀 / 漏杀** | 错拦好人 / 放走坏人 | 冤枉好人 / 放跑小偷 |

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| “风控就是拦” | 拦只是处置之一；验证、降额、复核、放行后补查都是处置 |
| “模型越准越好” | 风控的目标是成本最低，不是准确率最高 |
| “设备指纹能认出人” | 它只能关联“像同一台设备”，不能证明身份 |

## 读完自检（入门级 3 题）

**Q1** 为什么登录风控挂了要放行，交易风控挂了却要拒绝大额？

▸ 答案：因为代价不同：登录 fail-close 等于攻击者打满风控就能让全站登不进；交易大额 fail-open 等于开窗给资损。失败策略要按“哪种错误更贵”来定。

**Q2** 离线 AUC 0.95，上线效果却很差，最可能是什么问题？

▸ 答案：特征穿越或口径不一致。训练时用了预测时点之后的数据，或离线/在线窗口、时间口径不同，导致线上特征分布与训练分布不同，模型行为立刻偏离。

**Q3** 阈值从 0.5 调到 0.8，误杀少了、成本反而涨了，为什么？

▸ 答案：因为漏杀单价远高于误杀（示例 300 : 20）。阈值调高使 FP 从 40 降到 10，但 FN 从 20 涨到 45，成本从 6800 涨到 13700。阈值要按成本比选，不是按准确率选。
