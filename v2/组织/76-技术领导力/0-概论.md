## 5 分钟入门：先记住这 6 个词

| 词 | 一句话解释 | 生活类比 |
|---|---|---|
| **技术领导力** | 持续给思路与方案，不是职位 | 大家愿意跟着走的那个人 |
| **决策可逆性** | 错了能不能退，决定流程轻重 | 能退货的随便买，不能退的多想想 |
| **结论先行** | 第一句就说要他决定什么 | 先说要签字，再给材料 |
| **翻译成四件事** | 成本、风险、时间、收益 | 跟家里人说“多花多少、会不会坏” |
| **共识五层** | 承诺 / 认同 / 服从 / 观望 / 分裂 | 服从是“嘴上答应，脚下不动” |
| **愿景三句** | 三年后在哪、为何值得、下一步 | 先说目的地，再说怎么走 |

## 3 个最常见误解

| 误区 | 现实 |
|---|---|
| “领导力 = 管理职位” | 职位给决策权，领导力给“愿意跟随”；两者可以分离 |
| “沟通就是表达清楚” | 目标是让对方做出同一个决定，不是你说的字都对 |
| “共识 = 没人反对” | 没人反对常常只是“服从”，执行时会打折扣 |

## 读完自检（入门级 3 题）

**Q1** 一个决策“能一天回退”，该走评审吗？

▸ 答案：不必。可逆决策走轻流程（负责人拍板、事后知会），把评审资源留给不可逆决策。判据是可逆性：能快速退的，流程越重越浪费；退不回的，流程越轻越危险。

**Q2** 业务方问“这个技术方案有什么好处”，你该怎么答？

▸ 答案：翻译成四件事：多花多少钱、会不会挂、什么时候能上、能带来什么收益；并附“不做会怎样”。不要讲 QPS、延迟这类他无法比较的量纲。

**Q3** 会上大家都不反对，是不是就可以执行了？

▸ 答案：不一定。要判断共识层次：没人反对但没人主动补细节，多半是“服从”而非“承诺”。正确动作是记录反对意见、约定复盘时间，并把中立者拉进试点。
