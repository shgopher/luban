## 与书稿预期 / 常见文档不符
1. **版本**：书稿按 Superset 4.x（甚至 3.x）描述，`latest` 实为 **6.1.0**。
2. **数据库驱动**：6.1.0 镜像不含 psycopg2，官方 compose 之外需自行安装，否则 `superset version` 直接崩。
3. **chart 创建字段**：6.1 要求 `datasource_id`(int) + `datasource_type`("table") + `slice_name`；
   4.x 常见的 `"datasource": "1__table"` 不再适用（swagger 可证）。
4. **写 API 需要 CSRF**：仅 Bearer token 会 400 `The CSRF token is missing`；
   必须 `GET /api/v1/security/csrf_token/`（带 cookie jar）+ `X-CSRFToken` 才能 201。
5. **Swagger 路径**：`/swagger/v1/swagger.json` 返回 404；真实 OpenAPI 在 `/api/v1/_openapi`（需 token，452 KB）。
6. **`GET /api/v1/chart/{id}/data/` 在 6.1 报 400**：
   `{'result_type': ['Must be one of: columns, full, query, results, ...']}`，
   即使 query_context 存的是 `full`、并置 `query_context_generation=true` 仍 400；
   前端实际路径 `POST /api/v1/chart/data` 正常。属 6.1 该路由缺陷/行为变化。
7. CSP 未配置、flask-limiter 用内存存储两条 WARNING（不影响验证）。
