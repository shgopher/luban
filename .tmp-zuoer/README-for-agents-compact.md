# 补充约束（第二批任务必读）

上一批笔记写得太长导致任务失败。本批**硬性压缩**，但信息不许丢：

1. **每讲笔记 ≤ 40 行**，整个文件 ≤ 400 行。写成表格 + 短句，不写完整段落。
2. **逐讲落盘**：每读完一讲，立刻用 bash `cat >> .tmp-zuoer/notes/<批次>.md <<'EOF' … EOF` 追加，不要攒到最后一次写（避免整批丢失）。
3. 每个模板字段都要有，但只写**判据、数字、清单**；原文的铺垫、故事、广告、留言一律不写。
4. 「知识点全清单」允许合并同类项（如"五个学习阶段：①…②…"），但**数字与专有名词一个都不能少**。
5. 覆盖判定只给结论 + 1 个证据路径，不做长篇论证。
6. 落点建议 ≤ 3 条，每条 ≤ 2 行。

模板（字段名不变，内容压缩）：

```
## <讲号>｜<标题>
### 一句话结论
### 知识点全清单
- ①… ②… ③…
### 数字 / 公式 / 阈值
### 原话（≤ 2 句）
### 反例 / 坑
### 与 luban 的关系
- 覆盖判定：已覆盖/部分覆盖/缺失 — 证据 `v2/…`
- 落点建议：≤ 3 条
```
