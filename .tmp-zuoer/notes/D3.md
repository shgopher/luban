## 86｜程序员练级攻略：机器学习和人工智能
> 源文件 `.tmp-zuoer/txt/86丨程序员练级攻略：机器学习和人工智能.txt`，10012 字（2018-07-26）

### 一句话结论
机器学习只有两种范式——有标签的监督式与无标签的非监督式，先立住这个二分与「经典算法谱系」，再谈课程与工具，否则只会在资料海里迷失。

### 知识点全清单
- 两种范式：**监督式学习**＝被告诉过正确答案后的学习，需给「特征数据＋标签」样本集，学出规律/模式去判断未标注数据；**非监督式学习**＝没被告知答案，在大量很乱的数据里找共性/潜在关系，成本更高，也叫「特征点学习」。
- 监督式例子：手写数字识别——搜集尽可能多的手写数字图像，人工或算法标注谁是 1/2/3，这组数据叫**样本数据 / 训练数据（training data）**；算法学出各数字在不同手写体下的特征，再识别未标注手写数据。
- 非监督式例子：给一张照片找出与之相似的照片；对照监督式是「用一组狗的照片判断某照片是不是狗」。
- 非监督式应用：异常检测（信用卡诈骗/盗刷）、推荐系统（买了 A 又买 B；喜欢某文章/音乐/餐馆→可能喜欢某车/明星/地方）、交易型数据（某年龄段女性买某肥皂→可能在孕期；买儿童用品→关系链中有孩子）→ 精准营销提升销量。
- 前置：学机器学习前先学**数据分析 / Data Science**。
- 课程：Data Science Simplified **Part 1–11**（Principles and Process / Statistical Learning / Hypothesis Testing / Simple Linear Regression / Multivariate Regression / Model Selection / Log-Log Regression / Qualitative Variables / Interactions and Limitations / Classification / Logistic Regression）；UC Berkeley **Data 8** ＋电子书 Computational and Inferential Thinking；Learn Data Science（GitHub 电子书，线性回归/逻辑回归/随机森林/K-Means）；donnemartin/data-science-ipython-notebooks（TensorFlow、scikit-learn、Pandas、NumPy、Spark 复现经典例子）；Data Science Resources List；Awesome Machine Learning Courses。
- 视频课：**吴恩达 Coursera 免费机器学习课**（强烈建议从此入手，尽量拿满分，网易公开课有）＋ Deep Learning Specialization；**Google Deep Learning**（中英文，训练优化基本神经网络、CNN、LSTM，用 TensorFlow）；CMU Tom Mitchell 机器学习视频＋PDF；**2013 年 Caltech Yaser Abu-Mostafa《Learning from Data》**（更适合进阶）；Hugo Larochelle（Sherbrooke）Neural networks class；斯坦福《统计学学习》《机器学习》《卷积神经网络》《深度学习之自然语言处理》；MIT《神经网络介绍》《机器学习》《预测》。
- 书：**《Pattern Recognition and Machine Learning》**＝领域圣经、研究生教材，**不适合入门**，GitHub 有 Matlab 实现；《Understanding Machine Learning: From Theory to Algorithms》《The Elements of Statistical Learning 2nd》当手册/字典；**《Deep Learning》**（Goodfellow / Bengio / Courville，三部分：①数学工具与概念 ②成熟方法与技术 ③前瞻方向，官网 deeplearningbook.org，GitHub 有中文翻译）；《Neural Networks and Deep Learning》（豆瓣 **9.5**，讲激活函数、代价函数、随机梯度下降、反向传播、过度拟合与规范化、权重初始化、超参数优化、局部感受野、混合层、特征映射）；《Introduction to Machine Learning with Python》（以 Scikit-Learn 讲）；《Hands-On ML with Scikit-Learn and TensorFlow》。
- 文章：**Machine Learning is Fun!**（号称全世界最简单入门，有中文版）；Google Developers「ML Recipes with Josh Gordon」**9 集，每集不到 10 分钟**，从 Hello World 到 TensorFlow；Practical ML Tutorial with Python；Medium 的 ML-101 / ML for Humans；Rules of Machine Learning: Best Practices for ML Engineering；i am trask；The Unreasonable Effectiveness of RNN（为什么学 RNN ＋最简单的 NLP 形式）；Neural Networks, Manifolds, and Topology；Understanding LSTM Networks；Attention and Augmented RNN；Spotify 实习生用深度学习做音乐聚类。
- **监督式 6 大经典算法**：①决策树（自动化放贷、风控）②朴素贝叶斯分类器（垃圾邮件、新闻类别科技/政治/运动、情感正负、人脸识别）③最小二乘法 OLS（线性回归）④逻辑回归（一或多个变量表示二项式结果：信用评分、营销成功率、产品收入预测）⑤SVM（基于图像的性别检测、图像分类）⑥集成方法（一组分类器加权投票；原始为贝叶斯平均，现有纠错输出编码、Bagging、Boosting）。
- **非监督式 4 类**：①聚类（必知的 5 个：K-Means、Mean-Shift、DBSCAN、EM/GMM、Agglomerative Hierarchical）②PCA（压缩、简化数据便于学习、可视化）③SVD（PCA 是 SVD 的简单应用；首个人脸识别算法用 PCA＋SVD 得「特征面」线性组合降维再匹配身份）④ICA（揭示随机变量/测量值/信号集中的隐藏因素）。
- 动手与数据：8 Fun Machine Learning Projects for Beginners；**Awesome Public Datasets**（农业、生物、天气、计算机网络、地球科学、经济、教育、金融、能源、政府、健康、自然语言、体育）；Awesome Deep Learning / Most Cited Deep Learning Papers 等列表。

## 87｜程序员练级攻略：前端基础和底层原理
> 源文件 `.tmp-zuoer/txt/87丨程序员练级攻略：前端基础和底层原理.txt`，10102 字（2018-07-31）

### 一句话结论
前端只有三块地基——HTML5/CSS3/ES6 的语言层、**浏览器工作原理**、HTTP/HTTPS 协议层；工具（Maven 类比）不用专门学，动手就会，地基不牢则一切框架都是空中楼阁。

### 知识点全清单
- 三大基础：**HTML5、CSS3、JavaScript（ES6）**；CSS3 引申出 **Canvas（位图）/ SVG（矢量图）/ WebGL（3D 图）**，CSS 图形变换做渲染与动画效果。
- 硬骨头清单（本讲主线）：①JavaScript 核心原理（语言特性＋各种坑）②**浏览器的工作原理**③网络协议 HTTP（尤其 **HTTP/2**，及短连接/长连接/Stream/WebSocket 四种请求方式）④前端性能调优⑤框架（只给 React、Vue）⑥UI 设计（Material UI、Atomic Design）。
- 框架的底层拆解：**Virtual DOM 是底层技术，组件化是思想，状态管理是重点**；React 额外把**函数式编程**作为编程思想——这四层才是要研究的对象，不是 API。
- HTML5 三件套渲染：SVG/Canvas/WebGL 对应矢量/位图/3D，HTML5 小游戏因此繁荣；**首选学习地是 MDN**（Canvas API、WebGL API、Awesome SVG/Canvas/WebGL）。
- CSS：学好 CSS 的关键是**仔细读文档**（MDN Web Doc - CSS）；觉得难的两个真实原因＝文档没读透 ＋ **浏览器支持的标准不一致**；DRY 洁癖 → 用 **LESS / SaSS** 预处理；需 Reset/标准化库（**Normalize、MiniRest.css、sanitize.css、unstyle.css**）；CSS 框架：**Bootstrap**（Twitter）、Semantic UI（清新）、Foundation（响应式）、Bulma（基于 Flexbox）。
- JS 书单分层：**《JavaScript 语言精粹》**（语言本质，需反复读）→《JavaScript 忍者秘籍》（jQuery 作者，晦涩需琢磨）→**《Effective JavaScript》68 条**（标准化委员会专家，讲内部机制/陷阱/最佳实践）→ ES6（ES6 in Depth、阮一峰 ES6 教程、Modern JS Cheatsheet 1.6 万星、You Don't Know JS 六册：Up & Going / Scope & Closures / this & Object Prototypes / Types & Grammar / Async & Performance / ES6 & Beyond）。
- 编程范式词汇表（Glossary of Modern JavaScript Concepts Part1/2）：纯函数、状态、可变性与不可变性、指令型 vs 声明式、函数式编程、响应式编程、FRP；Part2 讲作用域与闭包、数据流、变更检测、组件化。
- **"How JavaScript Works" 系列 13 篇**（SessionStack CEO Alexander Zlatkov）：引擎/运行时/调用栈、V8 内部＋5 条写优化代码建议、V8 字节码、内存管理＋4 种常见内存泄漏、Event Loop＋async/await 5 个改进、WebSocket/HTTP2/SSE 选型、WebAssembly 对比、Web Workers 5 个用例、Service Worker 生命周期、Web Push、MutationObserver、渲染引擎与优化、网络层性能与安全、CSS/JS 动画性能。
- 浏览器原理必读：**《How browsers work》/《How Browsers Work: Behind the scenes of modern web browsers》**（有中文版，非常非常长，需耐心读完）；精简版看陈皓《浏览器的渲染原理简介》。
- Virtual DOM 必读：How to write your own Virtual DOM（1/2）、How Virtual-DOM and diffing works in React、The Inner Workings Of Virtual DOM、深度剖析：如何实现一个 Virtual DOM 算法；参考实现 Matt-Esch/Virtual-DOM、Maquette。**前提是先学完浏览器工作原理**。
- 协议层：《High Performance Browser Networking》（Google 高性能团队核心成员；主线是性能优化，从 **TCP/UDP/TLS** 讲到无线与移动网络，再讲 HTTP 底层细节与 **HTTP 2.0、XHR、SSE、WebSocket、WebRTC、DataChannel**）；HTTP/2 于 **2015 年**获批，主流浏览器已默认启用；两个 RFC：**RFC 7540**（协议本身）、**RFC 7541 HPACK**（头压缩）。
- 连接方式演进链：**Polling → Long Polling → Streaming → WebSocket**（"终极解决方案"），理解技术"缘由"比会用重要。

### 数字 / 公式 / 阈值
- 《Effective JavaScript》**68 条**；Modern JS Cheatsheet **1.6 万** star；JavaScript 30 秒代码 **2 万** star；Airbnb JS Style Guide **7 万+** star；"How JavaScript Works" **13 篇**；WebAssembly/V8 相关各 **5 条**建议/用例；内存泄漏 **4** 种；HTTP/2 于 **2015** 年获批。

## 89｜程序员练级攻略：UI/UX 设计

### 一句话结论
前端要懂设计，但懂的不是审美而是**设计方法论**——原子设计（组件化在界面上的同构）＋简约四策略（做减法）＋动画 12 法则（动效要有信息量）；设计语言只是这些方法论的品牌皮肤。

- 四本经典（判据型）：**《Don't Make Me Think》**（点石成金，短小、践行自身理论——"别让我思考"本身就是可用性判据）；**《简约至上》(Simple and Usable)**，Giles 20 多年交互设计经验，四策略：**合理删除 / 分层组织 / 适时隐藏 / 巧妙转移**，立场是"站在主流用户一边"从其真实需求出发。

- 为什么程序员该学原子设计：**它就是代码模块化/复用化的体现**，"像搭积木一样开发和设计网页"；模块化组件化 → 风格易规范、易维护 → **这个方法论直接催生了 Web 组件化的玩法**。权威源：Brad Frost 的电子书/博客/实验室 **Pattern Lab**（GitHub 可试）。

  - 其它：苹果 HIG（融合 Apple UI ＋ 看其审美思维）、**IBM 设计语言**（作者评"比较出众"）、Salesforce **Lightning Design System**（企业级）、Facebook Design。
