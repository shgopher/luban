# 25.2-mvcc：MVCC 版本链与可见性

[25.2-MVCC](../../../v2/L1-分布式原理/25-并发、冲突与幂等/25.2-MVCC.md) 的配套代码（Python 3，仅标准库）。

```bash
cd tools/examples/25.2-mvcc
python3 sim.py
```

输出节选：

```text
版本链（按提交时刻）：
  版本      值      提交时刻      写入事务  
  v1        1       0             基线      
  v2        2       5             T1        
  v3        3       8             T2        

写事务的当前读（写的前提，不是本事务的快照读）：
  T1 在 t=2 当前读 A=1 -> 写 A=2（悬挂，t=5 提交）
  T2 在 t=6 当前读 A=2 -> 写 A=3（悬挂，t=8 提交）

```

按提交时刻排版本链，看不同隔离级别下事务能看见哪个版本。
