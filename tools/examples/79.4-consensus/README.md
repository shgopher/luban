# 79.4-consensus：支持/中立/反对的共识层次

[79.4 冲突处理与共识建立](../../../v2/组织/79-技术领导力/79.4-冲突处理与共识建立.md) 的配套代码：三票输入，判定共识层次与下一步动作。

```bash
cd tools/examples/79.4-consensus
go run .
```

```text
支持=5 中立=0 反对=0 → 承诺：直接执行，写明负责人与截止时间
支持=4 中立=1 反对=0 → 承诺：直接执行，写明负责人与截止时间
支持=3 中立=2 反对=0 → 认同：执行，但把中立者拉进试点
支持=2 中立=3 反对=0 → 观望：补证据（试点/数据）后再决策
支持=1 中立=1 反对=3 → 分裂：停：先解决反对者的顾虑，或升级决策人
```

判定顺序是「先看反对，再看中立」：只要有明确反对且人数不少，就不是“再沟通一下”，而是停或升级。
