# 82.4-prototype-roi：原型值不值得做

[82.4 原型验证](../../../v2/附录/82-架构设计方法/82.4-原型验证.md) 的配套代码：把原型当一次赌注，按 `p* = (C + Delay) / (q × R)` 算回本点。

```bash
cd tools/examples/82.4-prototype-roi
go run .
```

输出节选：

```text
原型类型                         盒子     人天     延期      q      R    回本点p*
技术验证（兼容/可行性）                  3    6.0    0.0   0.50     40     0.30
性能验证（压测）                      2    4.0    2.0   0.60     25     0.40
交互验证（可用性测试）                   5    5.0    0.0   0.70     15     0.48
反例：可逆小改动                      3    3.0    6.0   0.30      8     3.75
```

回本点 ≤0.4 值得做，0.4–0.8 必须先写清放弃判据，>1 直接上、别做原型。参数（时间盒、人数、q、R）都是可改的假设值。
