# 21.14 PoW：哈希难题、双花概率与难度调整 (可运行复现)

对应正文：[21.14 PoW 与中本聪共识](../../../v2/L1-分布式原理/21-共识与选主/21.14-PoW与中本聪共识.md)

## 这段代码证明什么

| 实验 | 结论 |
|---|---|
| 前导零比特难题 | 平均尝试次数 ≈ `2^k`，但方差极大（最大可达均值的 3 倍以上） |
| 双花概率 | 攻击者算力 10%、6 个确认时约 `0.024%`；30% 时升到 `13%` |
| 模拟 vs 公式 | 蒙特卡洛与中本聪白皮书的闭式解在 10 万次试验下误差 < 2% |
| 难度调整 | 算力翻倍，同样 target 的出块时间减半，难度必须翻倍才能拉回 10 分钟 |

## 假设与边界

- 哈希难题用 `sha256(seed^nonce)` 模拟区块头，不涉及真实比特币的 80 字节头与 Merkle 根。
- 双花模型采用白皮书假设：诚实链先领先 `z` 块，攻击者在同一时间窗内挖到的块数服从 `Poisson(z·q/p)`。
- 不模拟孤块、自私挖矿、交易费与难度调整的实际周期，只验证概率量级。
- 数值会随随机种子小幅波动；`q=0.1, z=12` 在 10 万次试验下可能为 0。
