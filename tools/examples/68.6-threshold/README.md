# 68.6-threshold：阈值定在哪

[68.6 误杀与漏杀的权衡](../../../v2/L4-组件与技术/68-风控/68.6-误杀与漏杀的权衡.md) 的配套代码：把总成本写成阈值的函数扫一遍，找最低点，再用解析判据复核。

```bash
cd tools/examples/68.6-threshold
go run .
```

示例输出：

```text
好用户=100000 坏用户=2000（先验 2.0%），误杀单价=20，漏杀单价=300

阈值       误杀FP     漏杀FN     通过率       总成本
0.30     61128    12       38.12%    1226160
0.50     20248    153      78.34%    450860
0.60     8114     450      90.53%    297280
0.70     2534     931      96.47%    329980
0.90     109      1768     99.67%    532580

最低成本阈值=0.633：误杀=5701 漏杀=590 通过率=93.03% 总成本=291020
对照：阈值 0.50 的成本=450860，多花 54.9%
```

分数分布（好用户 μ=0.35、坏用户 μ=0.72）与成本单价（20 : 300）是**假设值**，随机种子固定为 42，输出可复现；换一组单价，最低点会移动，正文的解析判据就是用来快速估算这个移动方向的。
