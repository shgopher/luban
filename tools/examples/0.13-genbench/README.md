# 0.13-genbench：泛型、interface{} 与具体类型的基准

[0.13-编程范式](../../../v2/内功/0-内功/0.13-编程范式.md) 的配套代码。

```bash
cd tools/examples/0.13-genbench
go run .
```

输出：

```text
具体类型 []int64     3529774	       361.2 ns/op
泛型     []T         3282408	       356.1 ns/op
interface{} []any    2450918	       490.6 ns/op
```

泛型 `[]T` 与具体类型 `[]int64` 同速，`[]any` 多一次装箱、慢 1.4–1.8 倍。基准随机器波动：多次运行大致是 330–360 ns（具体/泛型）与 490–600 ns（`[]any`）。
