# 68.3-feature-ablation：三档特征的消融

[68.3 实时特征与决策](../../../v2/L4-组件与技术/68-风控/68.3-实时特征与决策.md) 的配套代码：10 万条样本、欺诈率 2.02%，每次去掉一档特征，看 AUC 与固定误杀率 1% 下的拦截率。

```bash
cd tools/examples/68.3-feature-ablation
go run .
```

输出节选：

```text
特征集合                        AUC      拦截率@FPR1%
仅离线(off)                  0.827          11.0%
离线+实时(off+rt)             0.841          12.8%   (ΔAUC=+0.014, Δ拦截=+1.8pp)
全量(off+rt+nrt)             0.852          13.9%   (ΔAUC=+0.011, Δ拦截=+1.1pp)
```

实时档 +0.014 AUC / +1.8pp，准实时档 +0.011 / +1.1pp——两档价值同量级，但准实时现算要 12–77ms，成本差一个数量级。仿真固定随机种子 7。
