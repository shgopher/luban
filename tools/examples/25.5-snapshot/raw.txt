  [t= 2.0] P0 发送 d2(20) 到 P1，通道队列=2
  [t= 3.0] P0 发送 d3(5) 到 P2，通道队列=1
  [t= 4.0] P1 收到 d1(10)：balance→10
  [t= 4.5] P1 发送 d4(7) 到 P2，通道队列=1
  [t= 5.0] P0 发起快照：记录本地状态 balance=100，向 c01/c02 发 marker
  [t= 5.0] P0 记录本地状态 balance=100，此后沿出边转发 marker
  [t= 5.5] P1 发送 d5(8) 到 P2，通道队列=2
  [t= 6.0] P1 收到 d2(20)：balance→30
  [t= 6.5] P2 收到 d3(5)：balance→5
  [t= 7.0] P1 收到 c01 的第一条 marker
  [t= 7.0] P1 记录本地状态 balance=30，此后沿出边转发 marker
  [t= 7.5] P2 收到 c02 的第一条 marker
  [t= 7.5] P2 记录本地状态 balance=5，此后沿出边转发 marker
  [t= 8.0] P2 收到 d4(7)：记入 c12 的通道状态
  [t= 9.0] P2 收到 d5(8)：记入 c12 的通道状态
  [t=10.0] P2 收到 c12 的 marker：通道状态=[d4 d5]

  P0 本地状态=100  已应用消息=[]

      消息覆盖：已发 5 条，缺失=[]，重复=[]
      marker 数=3（= 边数 3）；先于 marker 被漏掉的消息=[]
      判定：一致（每条消息恰好出现一次，总额对得上）

=== 运行 B：非 FIFO 通道（marker 在 c02 上超过 d3） ===
事件时间线（节选）

  [t= 2.0] P0 发送 d2(20) 到 P1，通道队列=2
  [t= 3.0] P0 发送 d3(5) 到 P2，通道队列=1
  [t= 4.0] P1 收到 d1(10)：balance→10

  [t= 5.0] P0 的 marker 在 c02 上超车（非 FIFO）
  [t= 5.5] P1 发送 d5(8) 到 P2，通道队列=2
  [t= 6.0] P1 收到 d2(20)：balance→30
  [t= 6.5] P2 收到 c02 的第一条 marker

  [t= 7.5] P2 收到 d3(5)：晚于 marker，更新实时余额但不进快照
  [t= 8.0] P2 收到 d4(7)：记入 c12 的通道状态
  [t= 9.0] P2 收到 d5(8)：记入 c12 的通道状态

  P2 本地状态=0  已应用消息=[]
     通道 c02 状态=[]（在途 0 条 / 0 元）
     通道 c12 状态=[d4 d5]（在途 2 条 / 15 元）

      消息覆盖：已发 5 条，缺失=[d3]，重复=[]
