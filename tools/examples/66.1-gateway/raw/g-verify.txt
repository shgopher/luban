# 环境: 2026-11-21 14:24:46 macOS 15.6 arm64 / go1.27.1 / redis 8.10.2 / gorilla websocket v1.5.3

### 1) 登录服务发一张一次性票据（真实系统由 49.5 的登录态服务写入）
$ redis-cli -p 16381 SET im:ticket:demo-1 u100 PX 60000
OK

### 2) 客户端带票建连（票据被 GETDEL 原子核销，无法重放）
$ wsclient -url ws://127.0.0.1:18081/ws?ticket=demo-1 -hold 6s &
CONNECTED ws://127.0.0.1:18081/ws?ticket=demo-1

### 3) 网关把这条连接登记进路由表
$ redis-cli -p 16381 KEYS 'im:route:*'
im:route:u100
$ redis-cli -p 16381 GET im:route:u100
gw1

### 4) 业务侧把下行 push 打到另一台网关 gw2（gw2 上没有这条连接）
$ curl -s -XPOST http://127.0.0.1:18082/api/send -d '{"uid":"u100","seq":7,"body":"hello"}'
{"code":"ok","gw":"gw1","receivers":1,"route":"redis"}

---- 客户端侧收到的帧 ----
CONNECTED ws://127.0.0.1:18081/ws?ticket=demo-1
FRAME {"body":"hello","seq":7,"type":"msg"}
