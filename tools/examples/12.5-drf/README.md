# 12.5-drf：主导资源公平（DRF）

[12.5-公平调度算法](../../../v2/L0-运行时底座/12-集群资源调度/12.5-公平调度算法.md) 的配套代码。

```bash
cd tools/examples/12.5-drf

```

输出节选：

```text
== 形状 → 主导份额 ==
  A 任务 (1核,4G)  cpu份额 0.083  内存份额 0.167  主导资源=内存  Δd=0.167
  B 任务 (3核,1G)  cpu份额 0.250  内存份额 0.042  主导资源=CPU  Δd=0.250
  C 任务 (2核,2G)  cpu份额 0.167  内存份额 0.083  主导资源=CPU  Δd=0.167

== DRF 分配序列（每步选主导份额最小且放得下者）==
  第 1 步 选中 A  d 0.000→0.167  该用户累计 (1核,4G)
  第 2 步 选中 B  d 0.000→0.250  该用户累计 (3核,1G)
  第 3 步 选中 C  d 0.000→0.167  该用户累计 (2核,2G)
  第 4 步 选中 A  d 0.167→0.333  该用户累计 (2核,8G)
```

每个任务算 CPU/内存份额，主导资源决定 Δd，份额最小者先得。
