# 67.5-riskrule：规则短路与命中记录

[67.5 资金安全与风控联动](../../../v2/L4-组件与技术/67-交易与账务/67.5-资金安全与风控联动.md) 的配套代码：规则按顺序短路，命中即拒绝并记录原因。

```bash
cd tools/examples/67.5-riskrule
go run .
```

```text
u1  金额=8000   → 通过
u2  金额=60000  → 拒绝：超单笔限额
u1  金额=12000  → 拒绝：5 分钟频次超限
u3  金额=300    → 通过
```

顺序即优先级：限额类硬约束排在频次类前面，命中即停，后面的规则不再计算——省下的不只是时间，还有“多条规则同时命中时以哪条为准”的解释成本。
