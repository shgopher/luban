```text
表 A：每条进入的消息数（与并发无关，只随 N 变）
算法              N=5       N=10      N=50      备注                              
集中式            3         3         3         请求+授权+释放；外加协调者节点    
Lamport           12        27        147       请求+回复+释放 = 3(N−1)           
Ricart-Agrawala   8         18        98        请求+回复 = 2(N−1)，延迟回复当释放
令牌环（K=N 满载）  1         1         1         令牌每绕一圈服务 N 次，摊薄到 1 跳/次

表 B：每秒消息量（N=10，不同并发 K；各算法按自己的吞吐跑满 10s）
```

同一条闭环负载下比消息数与临界区吞吐：集中式 3 条消息但协调者成瓶颈。
