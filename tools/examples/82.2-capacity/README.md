# 82.2-capacity：QPS → 并发 → 机器数

[82.2-容量估算](../../../v2/附录/82-架构设计方法/82.2-容量估算.md) 的配套代码。

```bash
cd tools/examples/82.2-capacity
go run .
```

输出：

```text
下单       峰值QPS=8000   并发≈240   机器≈24 台（含冗余 1.5）
支付回调     峰值QPS=2000   并发≈240   机器≈15 台（含冗余 1.5）
查询       峰值QPS=30000  并发≈300   机器≈20 台（含冗余 1.3）
```

Little 定律算并发，再乘冗余系数换算机器数。
