# 32.5-rebuild-cost：全量重建 vs 增量重建

[32.5-投影与重建](../../../v2/L2-架构风格/32-数据模式/32.5-投影与重建.md) 的配套代码（Python 3，仅标准库）。

```bash
cd tools/examples/32.5-rebuild-cost
python3 rebuild_cost.py
```

输出节选：

```text
== 参数（本机计算） ==
事件总数 N=20,000,000  全量单条=200µs  增量单条=350µs
全量固定 S=900s  增量固定 V=120s  worker=4  写入速率=2000条/s
全量重建耗时 = S + N×c_full = 900 + 4000 = 4,900s (1.36h)

== 方案对比：全量 vs 增量（d = 需要重算的事件条数） ==
方案                   回放条数      耗时(s)    耗时(h)  机器成本(元)   重算历史(分钟)
全量重建           20,000,000      4,900     1.36     3.27      166.7
增量重放           16,000,000      5,720     1.59     3.81      133.3
增量重放           13,657,143      4,900     1.36     3.27      113.8
```

全量 S+N×c_full 与增量 V+d×c_inc 的交点，决定什么时候全量更省。
