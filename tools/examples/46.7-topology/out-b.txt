== 输入 ==
  读 30000 QPS / 写 600 TPS / 缓存吸收 50% / 陈旧预算 500ms
  单表 500 万行 / 单库 120 GB / 3 AZ / RPO 5s / RTO 300s

== 决策链 ==
  1. 写侧：600 TPS 在安全线 2800 内（水位 21%）→ 写仍可单主
  2. 容量：单表 500 万行、单库 120 GB 未超阈值 → 不因容量分片
  3. 读侧：30000 QPS ×(1-缓存 50%)=15000，再乘 AZ 冗余 1.50 → 需 22500 QPS，单副本 12000 → 2 个副本
  4. 扇出：2 个副本 × 1.5 MB/s = 3 MB/s 主库上行
  5. RPO≤5s：异步复制通常满足（丢最近 1ms–数秒），但要接受切换时丢尾部
  6. RTO≤5min：脚本化切换 + 值班可执行，需预演过
  7. 成本：3 个盒子（1 主 + 2 从）× 1500 元 = 4500 元/月；每万读 QPS 1316 元/月

== 结论 ==
  拓扑：一主 2 从（异步）
  理由：读需扩展、可容忍秒级丢失：异步复制最便宜
  读能力：34200 QPS（水位 44%）
  可用性：MTTR 300s × 每月 1 次故障 → 年停机 1.00h，可用性 99.9886%（3.94 个 9）
  费用：4500 元/月，54000 元/年

== 陈旧预算 ==
  陈旧预算 ≤1s：会话粘滞 + 短 TTL 缓存 + 写后读主，三件套一起上

== 决策记录（ADR 片段）==
  决定：数据库采用「一主 2 从（异步）」。
  依据：读需扩展、可容忍秒级丢失：异步复制最便宜；读 30000 QPS 需 2 个副本（含 AZ 冗余 1/(1-1/3)=1.5）；RPO=5s 由异步复制兜住，不额外付半同步的 RTT；RTO=300s 决定切换方式。
  代价：每月 4500 元；主库扇出 3 MB/s；故障时年停机预算 1.00 小时。
