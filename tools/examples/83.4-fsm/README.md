# 83.4-fsm：状态机的三项检查

[83.4 时序图与状态图](../../../v2/附录/83-架构文档与表达/83.4-时序图与状态图.md) 的配套代码：对一张订单状态机做三项检查——不可达状态、无出口且非终态、终态是否齐全。

```bash
cd tools/examples/83.4-fsm
go run .
```

示例输出：

```text
检查完成：4 个状态可达，2 个终态
```

把 `states` 或 `edges` 改一下就能看到失败输出：删掉 `INIT → PAID` 会报「不可达」，把 `SHIPPED` 的出边删掉会报「无出口且非终态」。这类问题评审时看不出来，跑一遍就露馅。
