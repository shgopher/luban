# 78.2-platform-roi：平台团队的自助率与 ROI

[78.2 平台团队与中台](../../../v2/组织/78-技术组织设计/78.2-平台团队与中台.md) 的配套代码：把「平台值不值得建」落成一道算术题。

模型参数（**假设值**，改常数即可重算）：月操作 2000 次、单次人工 1.5h、平台处理每单 1.0h、业务方等待 0.5h、建设 6 人 × 160h/月。

```bash
cd tools/examples/78.2-platform-roi
go run .
```

输出节选：

```text
模式       自助率      月工单量      平台人力(建设+服务)      净节省h/月         节省/投入
工单制      10%      1800      17.2             -660           -0.24
半自助      60%      800       11.0             840            +0.48
全自助      90%      200       7.2              1740           +1.50

回本自助率 = 平台建设工时 ÷ 全手工总工时 = 960 ÷ 3000 = 32.0%
建设投入(人) → 回本自助率：  2人=10.7%  4人=21.3%  6人=32.0%  9人=48.0%  12人=64.0%
```

回本线与人力单价无关（公式两边同乘单价），只与操作量、单次人工、建设投入有关——这是正文那条反直觉结论的来源。
