# 21.13 PBFT：quorum 相交、消息数与视图切换 (可运行复现)

对应正文：[21.13 PBFT](../../../v2/L1-分布式原理/21-共识与选主/21.13-PBFT.md)

## 这段代码证明什么

穷举所有 quorum 组合，把 PBFT 安全性的算术部分跑成可核对的表：

| 检查 | 结论 |
|---|---|
| `n=4, q=3` | 任意两个 quorum 至少交 2 个节点 → 至少 1 个诚实 |
| `n=4, q=2`（照抄崩溃模型） | 存在完全不相交的两个 quorum → 两个主可以各自提交 |
| 每请求消息数 | `n=4` 时 28 条（不含签名与重传），渐近 `2n²` |
| 视图切换 | commit quorum 与 view-change quorum 必交 `f+1`，新主必能学到已提交请求 |

## 跑法

```bash
cd tools/examples/21.13-pbft
go run .
```

无外部依赖、无网络、无随机数。

```text
=== 视图切换：新主必须拿到哪些证据 ===
  n=4 f=1：commit quorum=[0 1 2]，view-change quorum=[1 2 3]
  交集=[1 2]（2 个），其中至少 1 个诚实 → 新主必能学到该请求
  ✓ 交集 ≥ f+1，满足 PBFT 的跨视图安全条件
```

## 假设与边界

- 只做组合数学检查，不模拟真实消息时序、签名校验和超时。
- 消息数按「每个副本向其他所有副本广播」计，不含重传、检查点与 new-view 消息。
- 视图切换只验证「交集存在」，不验证新主选择日志的具体算法。
