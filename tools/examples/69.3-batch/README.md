# 69.3-batch：上行合并省多少字节

[69.3 海量连接与消息](../../../v2/L4-组件与技术/69-物联网/69.3-海量连接与消息.md) 的配套代码：100 台设备各发 10 条约 50B 的 JSON 遥测，对比「逐条发」与「按 1s 窗口合并」。

```bash
cd tools/examples/69.3-batch
go run .
```

输出：

```text
逐条上报：1000 条，共 54000 字节
合并上报：1 条，共 18464 字节
合并后为原来的 34.2%，省 65.8% 字节
```

省下来的是**重复的元数据**（设备名、主题、批次头从 1000 份变成 1 份），不是数据本身。代价是等窗口的延迟与整批重放的粒度——所以遥测能合，事件和命令不要合。
