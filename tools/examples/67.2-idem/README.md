# 67.2-idem：幂等键的最小演示

[67.2 幂等与防重](../../../v2/L4-组件与技术/67-交易与账务/67.2-幂等与防重.md) 的配套代码：同一幂等键的第二次请求返回第一次的结果，而不是再执行一次。

```bash
cd tools/examples/67.2-idem
go run .
```

示例输出：

```text
第 1 次: 扣款成功，流水号 T20261031001
第 2 次: 重复请求，返回首次结果: 扣款成功，流水号 T20261031001
实际扣款次数=1
```

这里用内存 map 演示语义；生产环境的幂等键要落库或进 Redis，并用唯一索引/条件更新保证「检查 + 写入」的原子性（见正文的状态机幂等一节）。
