# 77.2-teamfit：按「面向谁 + 交付什么 + 复杂度」选团队类型

[77.2 四种团队类型](../../../v2/组织/77-康威定律与团队拓扑/77.2-四种团队类型.md) 的配套代码：把四个判据写成一个分类函数，看五个真实团队名会落到哪一类。

```bash
cd tools/examples/77.2-teamfit
go run .
```

示例输出：

```text
订单       → 流对齐团队            端到端拥有一个业务流，独立部署
支付网关     → 流对齐团队            端到端拥有一个业务流，独立部署
容器平台     → 平台团队             把内部能力做成产品：SLA + 文档 + 自助
风控引擎     → 复杂子系统团队          按稀缺专长组队，接口按 X-as-a-Service 提供
数据中台     → 平台团队（先拆）         服务数 > 5，按能力域拆分，否则平台自己变成瓶颈
```

分类规则是正文那张「四种团队类型」表的直接翻译；「先拆」分支对应表中「服务数 > 5，平台自己会变成瓶颈」那条反模式。
