# 78.4-interface-cost：接口人数量与响应时间的排队模型

[78.4 跨团队协作与接口人](../../../v2/组织/78-技术组织设计/78.4-跨团队协作与接口人.md) 的配套代码：把「接口人机制」拆成基础处理 B、排队等待 W（M/M/1）、跨接口人协调 `p*C` 三段，逐 N 扫描找延迟与成本的最优点。

```bash
cd tools/examples/78.4-interface-cost
go run .
```

输出节选（负载 R=1.20 件/天）：

```text
[负载 R=1.20 件/天] N=1:2.02 N=2:1.02 N=3:1.02 ...
  → 延迟最优 N=2（1.02天）；成本最优 N*=2 T=1.02天 ρ=0.37 成本=3.26人天/天
  → 直接对接：T=1.75天，成本=1.05人天/天
```

正文那条反直觉结论（**一个过载的单接口人平均响应 2.02 天，比不设接口人直接对接的 1.75 天还慢**）就是 `N=1` 这一行。所有参数是仿真假设，改文件顶部的常数即可重算。
