# 77.4-team-size：沟通路径与团队规模

[77.4 认知负荷与团队规模](../../../v2/组织/77-康威定律与团队拓扑/77.4-认知负荷与团队规模.md) 的配套代码：算两笔边际账（加人、拆分）与一条有效产能曲线。

模型参数（**假设值**）：名义 40h/周、可深度工作 28h/周、每条沟通路径 3h/周。

```bash
cd tools/examples/77.4-team-size
go run .
```

输出节选：

