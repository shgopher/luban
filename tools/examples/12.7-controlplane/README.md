# 12.7 控制面形态：集中式 / 非集中式 / 混合的代价 (可运行复现)

对应正文：[12.7 集中式与非集中式](../../../v2/L0-运行时底座/12-集群资源调度/12.7-集中式与非集中式.md)

## 这段代码证明什么

把三种控制面形态的代价算成同一组数字：

| 形态 | 模型 | 结论 |
|---|---|---|
| 集中式 | M/M/1 排队 | 利用率 90% 时延迟是空载的 10 倍，99% 时 100 倍 |
| 两层 | offer 过期率 `1-e^(-λτ)` | 1 次/秒变更、思考 2 秒，86% 的 offer 过期 |
| 共享状态 | 两两冲突概率 | 冲突随调度器数量 `k²` 增长，`k=8` 时一轮冲突概率 94% |
| 分片 | 线性扩展 + 跨分片比例 | 吞吐线性涨，但跨分片比例 `1-1/N` 同步上涨 |

## 跑法

```bash
cd tools/examples/12.7-controlplane
go run .
```

无外部依赖、无网络，秒级完成。

## 假设与边界

- M/M/1 假设到达与服务都服从泊松/指数分布，真实控制面有批量与优先级，数字只看趋势。
- offer 过期率假设状态变更服从泊松过程，且框架决策时间固定为 τ。
- 冲突模型按“每一对调度器在窗口内至少一次状态变更”近似，未模拟具体资源竞争。
- 分片的“跨分片比例”按随机分片简化，真实系统取决于分区键设计（见 19.1）。
