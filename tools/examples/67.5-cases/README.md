# 67.5-cases：三级联动的 10 组用例

[67.5 资金安全与风控联动](../../../v2/L4-组件与技术/67-交易与账务/67.5-资金安全与风控联动.md) 的配套代码：按「金额区间 × 风险等级」的矩阵做表驱动决策，逐条核对期望处置与实际处置。

```bash
cd tools/examples/67.5-cases
go run .
```

输出节选：

```text
用例   金额       风险   限额      名单     期望       实际       结果
T01  500      低    5000    false  放行       放行       true
T02  6000     低    5000    false  二次验证     二次验证     true
T03  6000     中    50000   false  二次验证     二次验证     true
T04  6000     高    50000   false  人工复核     人工复核     true
```

10 组覆盖放行 / 二次验证 / 人工复核 / 拦截四档，以及限额升档与名单命中的优先级；矩阵本身是正文那张 4×4 表。
