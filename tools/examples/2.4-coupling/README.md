# 2.4-coupling：业务模型到系统边界的耦合账

[2.4-从业务模型到系统边界](../../../v2/需求/2-业务与领域建模/2.4-从业务模型到系统边界.md) 的配套代码（Python 3，仅标准库）。

```bash
cd tools/examples/2.4-coupling
python3 coupling.py
```

输出节选：

```text
每日跨域调用次数     切前 240,002  切后 30,045  变化 -87.5%
每日跨域强一致写入对 切前 120,000  切后 30,000  变化 -75.0%

边界被依赖数（fan-in）：
  营销域  切前 3  切后 0
  交易域  切前 1  切后 4
  财务域  切前 0  切后 0

需交易域发版的变更  切前 0 次/周  切后 10 次/周（发布能力 5 次/周，缺口 +5 次/周）

```

切边界后跨域调用降 87.5%、强一致写入对降 75%、fan-in 归零。
