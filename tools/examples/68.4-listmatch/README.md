# 68.4-listmatch：名单优先级

[68.4 名单与画像](../../../v2/L4-组件与技术/68-风控/68.4-名单与画像.md) 的配套代码：黑名单拒绝、白名单放行、灰名单降额/复核，优先级高于规则。

```bash
cd tools/examples/68.4-listmatch
go run .
```

输出：

```text
命中黑名单 → 直接拒绝
```

名单是**确定性事实**，所以在规则引擎里优先级最高：命中就不必再算特征、跑模型（规则引擎见 [68.2 规则引擎](../../../v2/L4-组件与技术/68-风控/68.2-规则引擎.md)）。
