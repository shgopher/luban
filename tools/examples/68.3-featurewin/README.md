# 68.3-featurewin：实时特征的滑动窗口

[68.3 实时特征与决策](../../../v2/L4-组件与技术/68-风控/68.3-实时特征与决策.md) 的配套代码：5 分钟窗口内的交易笔数与金额。

```bash
cd tools/examples/68.3-featurewin
go run .
```

```text
近 300 秒：笔数=6 金额=2400
判据：窗口内笔数 > 5 或金额 > 1000 → 触发频次规则
```

窗口的边界（`<=` 还是 `<`）和口径（事件时间还是处理时间）决定同一笔会不会被算两次、延迟数据算进哪个窗口——正文那两条细节的代码就在这里。
