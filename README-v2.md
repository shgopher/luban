# 技术架构 · 完整知识目录

> **唯一一把尺子** (每章都能回答 “属于哪一层、哪一维”)：
>
> **需求 → 技术 → 组织 → 附录**
> - **需求** = 架构的输入 (要什么、有什么约束)
> - **技术** = 严格六层 L0–L5 (底座)+ 应用层 (领域应用)
> - **组织** = 架构与人的关系
> - **附录** = 方法、案例、参考 (**不是知识域**，是练习与查证材料)
>
> **边界**：覆盖 “一个要对公司技术架构负责的人” 所需知识。
> **不含**：具体语言语法细节、算法竞赛、纯学术论文、产品经理职责。
>
> 全书 **11 篇 · 83 章 · 524 节**。
