## 2. 约束与假设

## 3. 方案总览
- 架构图：<上下文图 + 容器图>
- 一次请求的路径：<客户端 → ... → DB>

<表结构、索引、数据归属、迁移方案>

## B.5 架构评审打分表

| 维度 | 1 分 | 3 分 | 5 分 | 得分 |
|---|---|---|---|---|
| 可扩展性 | 流量翻倍即崩 | 可水平扩展 | 十倍流量有预案 | |
| 可用性 | 单点明显 | 主备可切换 | 多活/自动恢复 | |
| 成本 | 明显浪费 | 匹配规模 | 有成本模型 | |
| 复杂度 | 团队维护不了 | 可维护 | 简单且清晰 | |
| 可运维性 | 手工部署 | 有监控 | 自助发布+可观测 | |

评审结论：**通过 / 有条件通过（列出条件）/ 不通过（列出原因）**。
