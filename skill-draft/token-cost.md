# token 账本：跨篇协作到底多花多少

> **一句话**：每篇多花 **+12.8k token（约 +94%）**——其中 10.3k 是「读一遍全文目录」，1–2k 是筛选与校验，2.6k 是规范本身；换来的是不漏节、不撞车。

---

## 一、规则（决定成本的那一条）

| 读什么 | 读多少 | 为什么 |
|---|---|---|
| **目录** | **全读**（14,754 字） | 只占全书 4.7%，是唯一「让你看到没想到的节」的入口；grep 只找得到你想到的词 |
| **正文** | **只读相关的 1–3 篇** | 31 万字 ≈ 22 万 token，通读一次上下文就没了 |
| 候选节的「一句话」 | 全读（3–8 条） | 决定某篇要不要精读，最便宜的一层 |
| 索引文件 | **只查不读** | 524 节 ≈ 7.6 万字，`cat` 一次 5 万 token |

> 🔑 **读什么由目录定，读多深由一句话定。**

---

## 二、口径（先说假设，否则比例没意义）

| 项 | 取值 | 来源 |
|---|---|---|
| token/字 | **0.7**（中文粗估） | 保守估计；tokenizer 波动 ±30%，但**比值稳定** |
| 一节正文 | 8,166 字 ≈ **5.72k** | `v2/` 实测：310,299 字 ÷ 38 节 |
| 输出 | 5.72k | 与成稿同量级 |
| **基线** | `原 skill 2.10k + 素材 5.72k + 输出 5.72k = 13.54k` | 「完全不考虑跨篇」的写法 |

---

## 三、每项实测值

| 读什么 | 字符数 | ≈ token | 何时付 |
|---|---|---|---|
| 原 `SKILL.md`（153 行） | 3,000 | 2.10k | 每次加载 |
| 新 `SKILL.md`（230 行，B 装法） | 5,483 | 3.73k | 每次加载 |
| **全文目录 README-v2** | 14,754 | **10.32k** | 每篇（一次会话可复用） |
| `-q` 筛选（2 次查询） | ~600 | 0.42k | 每篇 |
| `check-refs --quiet` | 605 | 0.42k | 每篇 |
| 一章 / 一节正文 | 8,166 | 5.72k | 只对精读的 1–3 篇 |
| 索引生成 | 0 | **0** | 脚本跑，不进上下文 |

---

## 四、每篇账本

| 读法 | 每篇 token | 增量 | 比例 | 100 篇 |
|---|---|---|---|---|
| 基线：只读素材，不看目录 | 13.54k | — | — | 1.35M |
| **目录 + 精读 1 篇相关** | 26.33k | **+12.79k** | **+94%** | 2.63M |
| 目录 + 精读 2 篇相关 | 32.05k | +18.51k | +137% | 3.21M |
| 目录 + 精读 3 篇相关 | 37.77k | +24.23k | +179% | 3.78M |
| 对照：每次通读全书正文 | 238k | +224.5k | +1655% | 23.8M |

**目录 + 1 篇** 的构成：`目录 10.32k · 筛选 0.42k · 精读 5.72k · 校验 0.42k · 规范 3.73k（替代原 2.10k，净 +1.63k） · 输出 5.72k`

### 两个降本手段（都不改变规则）

| 手段 | 效果 | 代价 |
|---|---|---|
| **一次会话连写多节**：目录只读一次 | 写 5 节 → 每节 **18.07k（+33%）** | 会话要连着开，别一节一个会话 |
| **先读一句话再决定精读**：候选 5 篇里只深读 1–2 篇 | 每少精读 1 篇省 5.72k | 需要判断力，不能全凭感觉跳过 |

> 🔑 目录 10.3k 是**固定接头费**，和写几节无关。写得越多，它摊得越薄——**这也是为什么「一次会话写一串相关节」比「一天写一节」便宜得多**。

## 五、和「用 grep 替代读目录」比

| 方案 | 每篇 | 比例 | 风险 |
|---|---|---|---|
| 读全目录 + 精读相关（现行） | 26.33k | +94% | 基本不漏 |
| 只 grep、不读目录（已废弃） | 16.57k | +22% | **漏同义词、漏没想到的节**；省下 9.8k，代价是撞车返工（一次约 17k） |

差 9.8k（约 37%），但返工一次就是 17k，且返工往往在写完 8,000 字之后才发现。**不省这一笔。**

---

## 六、值不值

| 防线 | 没有它（你书里已存在） | 有它 |
|---|---|---|
| 悬空引用 | 6 条指向未写节、未标待补 | 一条命令列全，交付前清零 |
| 编号错配 | 40.1「见 26.3 依赖倒置」实为 26.2 | 脚本比对标题，直接报出 |
| 孤岛 | 5 节出入皆 0（53.2/53.3 从别处到不了） | 入度 0 一眼可见 |
| 双主场 | 幂等 1.6:1，两篇各讲一版 | 3:1 判据 + 术语表报警 |

## 七、怎么复现

```bash
cd /Users/shgopher/Desktop/family/luban

python3 -c "from pathlib import Path; print(len(Path('README-v2.md').read_text()))"   # 目录 14,754
python3 -c "from pathlib import Path; print(len(Path('$HOME/.dsh/skills/luban-writing/SKILL.md').expanduser().read_text()))"

python3 skill-draft/make-index.py v2 && wc -m v2/_luban/chapters.md
python3 skill-draft/make-index.py v2 -q 幂等 | python3 -c "import sys;print(len(sys.stdin.read()))"
python3 skill-draft/check-refs.py v2 --quiet | python3 -c "import sys;print(len(sys.stdin.read()))"
```

换算：`token ≈ 字符数 × 0.7 ÷ 1000`。注意 macOS 上 `wc -m` 在 `LC_ALL=C` 时按字节算，中文字符数用 `python3 len()`。
