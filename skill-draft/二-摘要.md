## 二、全书视角：定位与跨篇协作

> **一句话**：先读全目录、只精读相关的几篇；主场讲透，客场只给结论 + 编号。完整规则见 `references/cross-refs.md`。

**铁律 6：先读目录，再动笔；一篇只讲一层，全书只讲一遍。** 同一知识点全书只设一个主场，客场只给一句自足的结论 + 编号。铁律 1 管「不掉肉」（相对原文），本条管「不重复」（相对全书）——**零丢失 ≠ 到处重复**。

### 动笔前四步

| 步 | 做什么 | 成本 |
|---|---|---|
| ① **读全文目录** | 篇 → 章 → 节 全看一遍（**必做**，一次会话只需一次） | 10.3k |
| ② **圈相关** | 标出 3–8 个可能相关的节（兄弟 / 上下游 / 可能重复的） | 0 |
| ③ **筛选** | `make-index.py . -q 核心词 同义词`，看候选的一句话 | ~0.4k |
| ④ **精读** | 只对真正相关的 1–3 篇读全文 | 5.7k/篇 |

> 🔑 **目录必读，正文精读。「读什么」由目录决定，「读多深」由一句话决定。** 正文 22 万 token 绝不能通读；目录 10.3k 必须读完——grep 只找得到你想到的词，目录让你看到你没想到的节。

```bash
python3 scripts/make-index.py .                    # 建索引：抽出每节「一句话」，供 ③④
python3 scripts/make-index.py . -d 本节编号          # 谁引用了我（入度 0 = 结论没被接住）
python3 scripts/check-refs.py . --quiet            # 收尾校验
```

> ⚠️ 禁止 `cat` 索引（524 节 ≈ 5 万 token）；但**不许用 `-q` 代替读目录**。

### 三条硬规则

| 规则 | 判据 |
|---|---|
| **主场 : 客场 ≥ 3 : 1**（同术语出现处数） | 低于 2 : 1 = 已经长出第二个主场 |
| **引用一律「编号 + 标题 + 相对路径链接」** | 站点里点得动；禁「前文 / 下文 / 后面会讲」：不可定位、导出即失效 |
| **可引用未写的节，不可替它下结论** | 写 `见 44.8 索引原理（待补）`，不许写它的方案 |

### 三种合法形态 / 五种禁止（都带链接）

| ✅ | 行内 `见 [24.6 本地消息表](…/24.6-本地消息表.md)`（12 字短标题）· 括号 `（[34.4 优化手段](34.4-优化手段.md)）`· 前文已说标题时只留编号 `本地消息表（[24.6](…)）` |
|---|---|
| ⚠️ | 指向**还没写**的节：`见 44.8 索引原理（待补）`——没文件就不写链接（死链比没链接更糟）。那一节写完后：行内「待补」由 `linkify-refs.py` **自动删**；关联块里的 `- 待补：44.8 …` 要**手工整行删掉**并入前置/下游，漏删报硬错误 |
| ❌ | 方向代词 · 裸编号 · **有标题没链接**（站点里点不动，读者只能手工翻目录）· 标题与目录不符 · 一页 8 个长链接 |

### 文末「关联」块（≤ 4 行，带链接，与正文行内引用一一对应）

```markdown
### 关联
- 前置：[24.4 TCC](24.4-TCC.md)、[24.6 本地消息表](24.6-本地消息表.md)
- 并列：[24.5 Saga](24.5-Saga.md)（补偿型，无冻结）
- 下游：[24.9 事务模型选型](24.9-事务模型选型.md)
- 待补：44.8 索引原理（未写，无链接）
```

**交付前**跑 `python3 scripts/check-refs.py .`：死链 0、裸编号 0、方向代词 0、**待补过期 0**（该节已写却还标待补，是硬错误）。
待补清单用 `check-refs.py . --todo` 看；每写完一节跑一次 `linkify-refs.py .` 回填链接。

> 💡 需要判断「两个主场怎么切」「层间怎么分工」「案例怎么复用」，或要改这套规范时，读 `references/cross-refs.md`（含四类引用关系、接缝、反模式、9 道自检题）。
